**Source:** D-sorganization/Tools#1706

## Description

## Assessment Category: Pragmatic Programmer — Estimating

**Severity:** Low — Inconsistent budget limits between documentation and CI.

### Finding

- CLAUDE.md and memory references state a **1200-line** file size budget
- CI workflow (`ci-standard.yml` line 135) runs: `python3 scripts/check_module_size_budget.py --max-lines 1500 --include src`
- `config/module_size_budget_baseline.json` lists 9 files with baselines up to 4,386 lines

The 1200 vs 1500 discrepancy means files between 1200-1500 lines are flagged by documentation standards but pass CI.

### Currently between 1200-1500 lines (gap zone):

1. `main_window.py` (rotation_converter UI) — 1,233 lines

### Recommendation

Align the CI budget with the documented 1200-line limit, or update documentation to reflect the actual 1500-line CI limit.
