# GH1686: Assessment: type:ignore count rose from 724 to 1147 (58% increase)

**Source:** D-sorganization/Tools#1686

## Description

## Assessment Category: B — Broken Windows (Technical Debt)

**Severity:** High — The count is moving in the wrong direction despite #1654 targeting reduction.

### Finding

Previous assessment: 724 `type: ignore` comments. Current count: **1,147** (1,115 in src/, 16 in tests/, 16 elsewhere). Of these, 1,137 are targeted (e.g. `type: ignore[misc]`) and only 4 are bare `type: ignore` — which is good practice. However the total number has grown 58%.

### Breakdown

- `src/`: 1,115 suppressions
- `tests/`: 16 suppressions
- Root-level: 16 suppressions

### Context

- #1654 targets reducing to under 200
- #1601 tracks 739 type:ignore + legacy directory exclusions
- mypy CI only checks changed files in delta mode, so type errors in untouched files never get caught

### Recommendation

1. Audit the 1,115 src/ suppressions — many may be stale after refactoring
2. Run `mypy --warn-unused-ignores` to find suppressions that are no longer needed
3. Prioritize `src/shared/python/` since it is the public API surface for downstream consumers
