# GH1703: Assessment: Pragmatic Programmer — Reversibility (pyproject.toml still references Black)

**Source:** D-sorganization/Tools#1703

## Description

## Assessment Category: Pragmatic Programmer — Reversibility

**Severity:** Low — Dead configuration creates confusion.

### Finding

`pyproject.toml` lines 144-146 contain:
```toml
[tool.black]
line-length = 88
target-version = ['py310']
```

The repo uses `ruff format`, not Black. This dead config could mislead contributors or tools that auto-detect formatters.

Additionally, `pyproject.toml` lists `black>=23.0.0` in `[project.optional-dependencies] dev` (line 98), adding an unnecessary dependency.

### Recommendation

1. Remove `[tool.black]` section from pyproject.toml
2. Remove `black>=23.0.0` from dev dependencies
3. Ensure editor configs (.editorconfig, .vscode/settings.json if they exist) reference ruff, not black
