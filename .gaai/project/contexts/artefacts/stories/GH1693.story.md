# GH1693: Assessment: 6 files duplicated between urdf_builder_gui/ and urdf_builder_gui/python/

**Source:** D-sorganization/Tools#1693

## Description

## Assessment Category: I — DRY (Don't Repeat Yourself)

**Severity:** Medium — Identical filenames exist in two locations, likely with diverging content.

### Finding

These `.py` files exist in BOTH `src/urdf_builder_gui/` and `src/urdf_builder_gui/python/urdf_builder_gui/`:
- `contracts.py`
- `__init__.py`
- `theme.py`
- `anthropometric_model.py`
- `urdf_generator.py`
- `preview_generator.py`

Also noted: `build_stylesheet` function is 161 lines and duplicated in both `theme.py` locations.

### Impact

Changes to one location may not be reflected in the other, creating silent divergence. Downstream consumers may import from either path depending on how `sys.path` is configured.

### Recommendation

Determine which is the canonical location and make the other a symlink or delete it. The `python/` subdirectory pattern suggests a packaging layout, so the top-level files may be legacy copies.
