# GH1689: Assessment: Dual ruff config (ruff.toml + pyproject.toml) with conflicting rules

**Source:** D-sorganization/Tools#1689

## Description

## Assessment Category: E — Entropy (Configuration Drift)

**Severity:** Medium — Two configs exist with different rule sets, confusing contributors.

### Finding

Both `ruff.toml` and `pyproject.toml [tool.ruff]` exist. Ruff resolves from `ruff.toml` (takes precedence), but `pyproject.toml` has different settings:

| Setting | ruff.toml | pyproject.toml |
|---------|-----------|----------------|
| target-version | py311 | py310 |
| select | E,F,W,I,B,UP | E,F,B,UP,I,T201 |
| T201 (print) | **Missing** | **Present** |
| W rules | Present | Missing |

Additionally, `pyproject.toml` still references `[tool.black]` (line 144-146) which is dead config since the repo uses ruff format.

### Recommendation

1. Consolidate into a single config source (prefer `pyproject.toml` for discoverability)
2. Or ensure both files are identical for overlapping settings
3. Remove dead `[tool.black]` section from pyproject.toml
