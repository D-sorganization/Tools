# GH1684: Assessment: ruff.toml lacks T201 rule — print() calls bypass CI linting

**Source:** D-sorganization/Tools#1684

## Description

## Assessment Category: N — Pragmatic Programmer (Tracer Bullets / Broken Windows)

**Severity:** High — CI says "All checks passed!" while 2 print() calls remain in production code.

### Finding

`ruff.toml` (the active config) selects rules `["E", "F", "W", "I", "B", "UP"]` but does NOT include `T201` (print detection). Meanwhile `pyproject.toml` includes `T201` in its `[tool.ruff.lint]` section, but ruff resolves settings from `ruff.toml` which takes precedence.

**Result:** `ruff check .` passes with zero violations despite `print()` calls in `src/rotation_converter/modern_robotics.py` (lines 1464, 1583). When T201 is explicitly checked, 746 violations are found across src/ (mostly in notebooks, but real violations exist in `.py` files).

### Evidence

```
$ python3 -m ruff check --show-settings 2>&1 | head 3
Resolved settings for: "UnifiedToolsLauncher.py"
Settings path: "ruff.toml"
```

```
$ python3 -m ruff check --select T201 src/ 2>&1 | wc -l
746
```

The failing tests in `tests/test_gh1655_print_to_logging.py` confirm `modern_robotics.py` still has print() calls and no logging import.

### Recommendation

Add `"T201"` to the `select` list in `ruff.toml` line 43. Add per-file-ignores for legitimate uses (CLI scripts, notebooks).
