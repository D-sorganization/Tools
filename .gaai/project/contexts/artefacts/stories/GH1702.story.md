# GH1702: Assessment: Pragmatic Programmer — Orthogonality (E501 globally suppressed)

**Source:** D-sorganization/Tools#1702

## Description

## Assessment Category: Pragmatic Programmer — Orthogonality

**Severity:** Low — A formatting rule is globally disabled, undermining the stated 88-char line limit.

### Finding

`ruff.toml` line 60 contains:
```toml
"**/*.py" = ["E501"]
```

This globally suppresses line-length violations for ALL Python files, even though:
- The repo states it uses 88-char line limit
- `ruff format` enforces 88 chars
- The E501 suppression means lines that `ruff format` cannot auto-fix (long strings, comments) are never flagged

### Impact

Developers writing long comments or string literals get no feedback. `ruff format` handles most cases, but manual review of unformattable long lines is lost.

### Recommendation

Remove the global E501 suppression. Instead, add targeted `# noqa: E501` to specific lines that genuinely need to exceed 88 chars (URLs in comments, etc.).
