# GH1548: Audit and reduce skip-heavy shared-package tests

**Source:** D-sorganization/Tools#1548

## Description

## Problem

Some shared-package tests skip due to optional dependencies, which is valid in some cases but leaves exported boundaries under-protected.

## Required Changes

- Audit existing skip/xfail use in tests touching exported shared packages
- Rework tests into deterministic unit tests where possible
- Move truly optional stacks into separate quarantined jobs
- Keep core provider-contract tests dependency-complete and non-skippable

## Acceptance Criteria

- Core shared-package contract tests do not rely on optional skips to pass
- Optional integrations are clearly separated from required provider coverage
- Skip debt is documented and materially reduced

## Acceptance Criteria

1. The issue described in #1548 is resolved
2. All new code has tests (TDD)
3. `ruff check` passes on modified files
4. No new `print()` calls in `src/`
5. PR created targeting `staging` branch with clear description
