# Memory Delta: GH1468

## Observations

### Pattern: LoD Fixes Often Pre-empted by Prior Work

In this story (and several preceding similar stories), the DbC violation fixes flagged in the
GitHub issue description had already been implemented by prior delivery sessions. The LoD fixes
were the actual remaining work.

This pattern suggests the adversarial assessment tooling generates findings at issue-creation time,
and delivery sessions address them incrementally. Downstream stories in the same batch may find
partial or complete implementation already done.

**Implication for Discovery:** When refining adversarial assessment stories, a pre-delivery scan
of the target files would allow more precise scoping of remaining work.

### Pattern: folder_tool Tests Require Extended PYTHONPATH

`src/folder_tool/` modules use bare imports (`from Folders_Tool_r0 import ...`) that require
`src/folder_tool` to be on PYTHONPATH. The standard `pythonpath = ["src"]` in pyproject.toml
is insufficient. Running with `PYTHONPATH="src:src/folder_tool"` enables all 108 tests to pass.

This is a structural issue in the `folder_tool` module's import design, not a test configuration
problem. The pre-existing 11 import errors in the default test run are caused by this.
