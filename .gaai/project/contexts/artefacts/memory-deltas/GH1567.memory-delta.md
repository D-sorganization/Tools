# GH1567: Memory Delta — Tools/Tools_Private Strategic Split

## New Decisions to Ingest

### DEC: Tools/Tools_Private Repository Split

**Decision:** Proprietary industrial process simulation modules are maintained in the
private `D-sorganization/Tools_Private` repository, separate from the public `Tools`
shared library.

**Rationale:** IP protection for commercially-sensitive gasification and process simulation
algorithms. Separation allows different access controls and open-source consumer clarity.

**Criteria for public Tools vs Tools_Private:**
- Public Tools: shared library code (DSP, URDF, calculators, P&ID, themes) — no trade secrets
- Tools_Private: proprietary simulation modules — gasification, industrial process, plasma

**Migrated modules (19):** acid_gas_dewpoint, baghouse_calculator, dwsim_model,
electrode_advisor, flare_calculator, gasification_equilibrium, glass_bath_fea, hcl_reactor,
psa_package, rrt_path_planner, scientific_modeling, scrubber_calculator, shared,
solar_system_model, syngas_compression, syngas_water_calculator, thermal_profile_predictor,
trc_vessel_designer, wgs_reactor.

**CI parity:** Tools_Private maintains same ruff/mypy/CI standards as Tools.

**Reference:** GH1567, `feat/remove-private-modules`, GH1575 (CI validation).
