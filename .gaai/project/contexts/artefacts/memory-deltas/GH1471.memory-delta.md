# GH1471 Memory Delta

## New Patterns

### Pattern: LoD Fix for External Library Objects
When working with external library objects (e.g., pygmsh Mesh), extract multiple
attribute accesses to local variables before use:
```python
# Before (LoD violation)
nodes = mesh.points.T
elements = mesh.cells_dict.get("tetra", ...)

# After (compliant)
mesh_points = mesh.points
mesh_cells = mesh.cells_dict
nodes = mesh_points.T
elements = mesh_cells.get("tetra", ...)
```

### Pattern: DbC for Optional ndarray Parameters
For optional numpy array arguments (defaults to None), validate only when provided:
```python
if depths is not None:
    assert len(depths) > 0, "depths must be a non-empty array"
    assert all(d >= 0 for d in depths), "all depths must be non-negative"
```

### Pattern: DbC for duck-typed Config Objects
For optional config objects passed by duck typing (Any | None), validate required
attribute presence rather than type:
```python
if electrode_config is not None:
    assert hasattr(electrode_config, "bath_diameter"), "..."
    assert hasattr(electrode_config, "glass_depth"), "..."
```
