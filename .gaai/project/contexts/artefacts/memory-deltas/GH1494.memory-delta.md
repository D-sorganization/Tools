# GH1494 Memory Delta

## Pattern: sys.modules Mock for Optional UI Dependencies

When testing modules that import optional UI test libraries (playwright, selenium, etc.) at the top level, use `sys.modules` injection before any imports:

```python
import sys, types
if "playwright" not in sys.modules:
    pw = types.ModuleType("playwright")
    sync_api = types.ModuleType("playwright.sync_api")
    sync_api.sync_playwright = MagicMock()
    sync_api.expect = MagicMock()
    pw.sync_api = sync_api
    sys.modules["playwright"] = pw
    sys.modules["playwright.sync_api"] = sync_api
```

Then use `importlib.reload(mod)` + `patch.object(mod, "sync_playwright", ...)` to control behavior per test.

## Pattern: LoD Fix for Playwright chains

Playwright API chains like `p.chromium.launch()` and `page.locator(sel).method()` are LoD violations. Fix by extracting intermediate objects:

```python
# Before
browser = p.chromium.launch(headless=True)
described_by = page.locator("#standardCondition").get_attribute("aria-describedby")

# After
chromium = p.chromium
browser = chromium.launch(headless=True)
condition_locator = page.locator("#standardCondition")
described_by = condition_locator.get_attribute("aria-describedby")
```
