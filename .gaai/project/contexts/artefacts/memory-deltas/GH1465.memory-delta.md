## Pattern: Headless Testing for PyQt6 Modules with upstream_drift_tools Dependencies

### Context

Modules in Tools_Private that inherit from `BaseCalculatorWindow` (from `upstream_drift_tools`)
cannot be imported in CI test environments without a special path setup. The `upstream_drift_tools`
package lives in `Tools/src/shared/python/`, not in `Tools_Private/src/shared/python/`.

### Pattern Established

A module-level `conftest.py` in the tests directory that:
1. Adds `src/<module>/python/` to `sys.path` for package importability
2. Attempts to find `upstream_drift_tools` from the sibling Tools repo (`gaai-fleet/Tools/src/shared/python/`)
3. Falls back to an in-process `MagicMock` mock hierarchy if the real package is unavailable
4. Provides a concrete `BaseCalculatorWindow` stub class for inheritance to work

Reference implementation: `src/flare_calculator/tests/conftest.py` (GH1465)

### Applicability

Applies to any Tools_Private module that:
- Has a `python/<module>/ui/pyqt6/main_window.py` with `BaseCalculatorWindow` inheritance
- Needs engine/logic tests (headless) that don't require a full Qt display

### Known Modules with this Pattern

- `src/flare_calculator/tests/conftest.py` (GH1465) — established here
- `src/electrode_advisor/tests/conftest.py` — partial (path setup only, no mock)
