# GH1700 Memory Delta

## New Pattern: Cross-Repo Import Exception Rule

**Context:** When tests import from `src.shared.python.*` paths that resolve via sys.path to
UpstreamDrift (symlinked repo), the PreconditionError raised is from UpstreamDrift's own
`contracts.py` module object — NOT from the local Tools `contracts.py`.

**Rule:** Tests that exercise UpstreamDrift modules via absolute `src.shared.python.*` imports
MUST catch `from src.shared.python.contracts import PreconditionError`, not the bare
`from contracts import PreconditionError`. These are different class objects.

**Implication:** A future story to fix this properly would require ensuring both repos import
from the same contracts module instance (e.g., via shared package installation or by changing
UpstreamDrift's cross-repo pattern).

## Confirmed Convention

The canonical contracts import style in Tools is: `from contracts import require`
(bare import; resolves via `src/shared/python` in pytest.ini pythonpath).
`from src.shared.python.contracts import` is incorrect for Tools-internal code and
will break in packaged installs.
