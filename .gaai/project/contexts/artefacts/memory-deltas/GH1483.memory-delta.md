# GH1483 Memory Delta

## Pattern: Replace bare `assert` with explicit `raise TypeError`

**Context:** DbC violations identified by adversarial assessment across `src/rotation_converter/`.

**Established pattern (consistent with GH1484, GH1488, etc.):**
- Bare `assert x is not None, "..."` → `if x is None: raise TypeError("...")`
- Bare `assert x is not None` for typed args → `if not isinstance(x, ExpectedType): raise TypeError(...)`
- `require()` calls are already correct and should remain as-is.

**Rationale:** Python's `-O` flag disables `assert` statements silently; explicit `raise`
is unconditional and produces `TypeError`/`ValueError` (project DbC convention).

## Pattern: LoD Fix for Same-Type Private Attribute Access

**Context:** `Rotation.compose` accessed `other._q` (private slot) directly.

**Fix pattern:** Replace `other._private` with `other.public_accessor()` where a public
method exists. For `Rotation`, use `other.as_quaternion()`.

**Note:** This adds a copy operation (minor overhead). For rotation objects this is negligible.
If a class intentionally permits sibling access to private state (e.g. for performance),
document the exception explicitly.

## Disposition

Discovery should review and ingest this delta to update conventions.md with the
assert-replacement pattern if not already present.
