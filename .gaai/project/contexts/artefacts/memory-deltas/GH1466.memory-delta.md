# Memory Delta — GH1466

## Pattern Observed

**PyQt6 LoD compliance via module-level constants**

When Qt enum chains (`Qt.AlignmentFlag.X`, `QSizePolicy.Policy.X`) are repeated
across multiple methods in a single module, extract them as module-level constants
immediately after the import block. This eliminates LoD violations while keeping
the code readable and type-checkable.

## Suggested Memory Entry

Consider adding to `patterns/conventions.md`:

> **PyQt6 enum chains:** Any `Class.Namespace.Value` Qt enum used more than once
> per module MUST be extracted to a module-level constant named `_ENUM_VALUE`
> (e.g., `_ALIGN_CENTER = Qt.AlignmentFlag.AlignCenter`). Tests should use
> AST-based inspection to guard the convention without requiring PyQt6 to be
> installed in the test environment.
