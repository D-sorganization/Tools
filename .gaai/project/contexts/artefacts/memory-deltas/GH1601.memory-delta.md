# GH1601 Memory Delta

## Notable Patterns

### Pattern: Pre-declare + re-export for optional imports

The `import X as X` pattern combined with pre-declaration eliminates `no-redef`
and `assignment` type: ignore comments in try/except import fallback blocks.

```python
# Pre-declare with type annotation
MyClass: type[MyClassType] | None = None
try:
    from .module import MyClass as MyClass  # noqa: F401 — re-export
except ImportError as e:
    _import_errors.append(f"MyClass not available: {e}")
```

This is preferable over annotating in the except branch (which triggers `no-redef`).

### Pattern: ax: Any for matplotlib 3D Axes

When using `matplotlib.pyplot.figure.add_subplot(..., projection="3d")`, casting
the result to `Any` eliminates `attr-defined` errors for `set_zlabel`, `plot_surface`,
etc. without requiring mypy.ini module-level overrides:

```python
from typing import Any
ax: Any = self.canvas.fig.add_subplot(111, projection="3d")
ax.plot_surface(...)  # no type: ignore needed
```
