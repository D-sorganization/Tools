# GH1491 Memory Delta

## Pattern: Private helper methods still require DbC preconditions

The adversarial assessment flagged that private/internal helper functions
(`_stream_reader`, `_run_matlab_script`, `convert_image_mode`) lacked preconditions
despite being called from public functions that had their own contracts.

Convention established: DbC `require()` preconditions apply at **every** function
boundary where the argument type or value could be wrong — including private helpers,
static methods, and functions called transitively from public APIs.

The `assert foo is not None` pattern (used in some older code) should be supplemented
or replaced by `require(foo is not None, ...)` from `src.shared.python.contracts`
for consistency and to raise `PreconditionError` (catchable by callers) rather than
`AssertionError` (stripped by Python -O flag).
