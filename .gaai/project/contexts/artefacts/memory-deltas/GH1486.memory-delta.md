# GH1486 Memory Delta

## Key Decision

**UpstreamDrift files are the authoritative source for `src.shared.python.*` in the test suite.**

The Tools repo has its own copy of `src/shared/python/` files, but because UpstreamDrift is on PYTHONPATH with proper `__init__.py` package structure (`src/__init__.py`, `src/shared/__init__.py`), Python resolves `src.shared.python` to UpstreamDrift's version — NOT the local Tools copy. Any DbC/LoD fix that needs to be exercised by the test suite must be applied to UpstreamDrift.

## Pattern

When addressing `src/shared` issues in the Tools adversarial assessment:
1. Check if `src.shared.python.*` tests load from UpstreamDrift (use `python3 -c "import src.shared.python.X; print(X.__file__)"` to confirm)
2. Apply fixes to BOTH the UpstreamDrift files AND the local Tools src/shared/python/ files
3. Run `tests/shared/` to verify

## LoD Fix Pattern

For 3-level attribute chains (`a.b.c`), extract intermediate:
```python
# Before
if node.func.id not in allowed:
# After
func = node.func
func_id = func.id
if func_id not in allowed:
```

For chained string method calls (`os.environ.get(...).lower().strip()`):
```python
# Before
val = os.environ.get("KEY", "").lower().strip()
# After
raw = os.environ.get("KEY", "")
val = raw.lower().strip()
```
