# GH1692 Memory Delta

## Pattern: ISP Sub-Mixin Extraction for Qt Mixin Classes

**Context:** When a non-QObject mixin used with QWidget grows beyond ~20 methods,
extract private sub-mixins (prefix `_`) by responsibility. The parent mixin inherits
from sub-mixins, maintaining the original import path and API.

**Why:** Qt's metaclass system prevents MRO-safe signals in mixins. This pattern
avoids introducing QObject inheritance while still enabling ISP decomposition.

**Guard pattern:** Add AST-based method count tests to CI using `ast.parse` + `ast.walk`.
These tests are `headless_safe` (no display required) and catch regression before review.
