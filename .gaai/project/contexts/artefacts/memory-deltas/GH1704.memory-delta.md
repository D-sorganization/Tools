# GH1704 Memory Delta

## New Patterns Worth Persisting

### Pattern: DbC in Process Calculators

**Domain:** process_calculators, contracts, DbC enforcement

**Pattern:** When adding DbC contracts to process engineering calculators, use domain helpers from `contracts.py` (`check_temperature`, `check_pressure`, `check_positive`, `check_non_negative`) rather than raw `require()` calls for physical-quantity inputs. This improves readability and ensures consistent error messages.

**Import line:** `from contracts import require, ensure, check_temperature, check_pressure, check_positive, check_non_negative`

**Established by:** GH1704

---

### Pattern: _ContractState.level vs DBC_LEVEL alias

**Domain:** contracts, DbC enforcement

**Decision:** Core contract primitives (`_handle_violation`, `require`, `ensure`, `invariant`) should read `_ContractState.level` directly rather than the `DBC_LEVEL` module-level alias. The alias exists for backward compatibility with external code that imports it, not for internal use.

**Established by:** GH1704

---

## Decisions to Extract

None — these are implementation conventions, not architectural decisions.
