# GH1648 Memory Delta

## Pattern: Absolute Imports Required in sys.path-Mounted Packages

**Domain:** Python packaging, shared libraries

**Observation:** `src/shared/python/` is placed on `sys.path` directly. Modules
in this directory are importable as top-level modules (e.g., `import cors`, `import contracts`).
Relative imports (e.g., `from .contracts import require`) only work when the module
is part of a package that was imported via its package path. When loaded as a top-level
module from a `sys.path` directory, relative imports raise `ImportError`.

**Rule:** All imports within `src/shared/python/` modules MUST use absolute imports.
Do not use relative imports (`from .module import ...`) in this directory.

**Correct pattern:**
```python
from contracts import require  # absolute — works with sys.path injection
```

**Incorrect pattern:**
```python
from .contracts import require  # relative — breaks when imported as top-level
```

**Note:** This applies to the `cors.py`, `contracts.py`, `safe_eval.py`, and any
future modules placed directly inside `src/shared/python/`.
