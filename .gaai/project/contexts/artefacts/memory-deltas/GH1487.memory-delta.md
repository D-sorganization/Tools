# GH1487 Memory Delta

## New Patterns Worth Persisting

### 1. Outer Namespace Package Bootstrap Pattern

For modules with a `python/` subdirectory layout (e.g., `src/<module>/python/<module>/`), the outer `__init__.py` should bootstrap the inner python path:

```python
import sys
from pathlib import Path

_PYTHON_DIR = str(Path(__file__).resolve().parent / "python")
if _PYTHON_DIR not in sys.path:
    sys.path.insert(0, _PYTHON_DIR)
```

This mirrors the `urdf_builder_gui` pattern and enables `from <module>.submodule import X` to resolve correctly under pytest.

**Reference:** `src/signal_processing_studio/__init__.py`, `src/urdf_builder_gui/__init__.py`

### 2. Qt Signal LoD Wrapper Pattern

To avoid LoD violations on Qt signal connections (`action.triggered.connect(slot)`), extract into a module-level helper:

```python
def _connect_action(action: QAction, slot: object) -> None:
    """Connect a QAction's triggered signal to a slot."""
    if action is None:
        raise ValueError("action must not be None")
    if slot is None:
        raise ValueError("slot must not be None")
    action.triggered.connect(slot)
```

**Reference:** `src/signal_processing_studio/python/signal_processing_studio/main_window.py`

### 3. Test Inner Package Import Resolution

When a test file in `src/<module>/tests/` needs to import from the inner `src/<module>/python/<module>/` package, the test file must:
1. Force the inner python dir to position 0 in sys.path (remove-then-insert, not just insert-if-absent)
2. Delete specific sys.modules entries (core package only, not tests subpackage)
3. Call `importlib.invalidate_caches()`

This is because pytest's `pythonpath = src` adds `src` first, and the outer namespace package gets cached before test code runs.

**Reference:** `src/signal_processing_studio/tests/test_signal_processing_studio.py`
