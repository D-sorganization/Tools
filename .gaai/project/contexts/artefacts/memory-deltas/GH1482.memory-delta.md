# GH1482 Memory Delta

## New Patterns Observed

### DbC Pattern: `assert` is Insufficient

All `assert x is not None` guards in `src/python` were replaced with explicit `TypeError`/`ValueError` raises. Pattern to add to conventions:

> Never use `assert` for DbC preconditions in production code. Use:
> - `if not isinstance(x, T): raise TypeError(f"x must be a T, got {type(x).__name__}")`
> - `if x < lower_bound: raise ValueError(f"x must be >= {lower_bound}, got {x}")`

This is consistent with existing conventions in other modules but was not being applied to `src/python`.

### LoD Pattern: `os.path.getmtime(path_obj)` Is a Spurious Chain

When `root_path` is already a `Path` object, `os.path.getmtime(root_path)` introduces a cross-module chain. Use `root_path.stat().st_mtime` instead — same result, 2-level chain.

### LoD Pattern: Manifest Path Traversal

`manifest_path.parent.name` and `manifest_path.parent.glob(...)` are 3-level chains. Standard fix: `parent_dir = manifest_path.parent` then `parent_dir.name` / `parent_dir.glob(...)`.

No new architectural decisions. Changes are consistent with existing DbC/LoD conventions.
