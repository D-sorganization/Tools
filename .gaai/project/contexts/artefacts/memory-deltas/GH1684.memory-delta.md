# Memory Delta: GH1684

## Pattern: Adding New Ruff Rules to Active Config

When adding a new lint rule to `ruff.toml`, pre-existing violations in non-src files
(CLI scripts, test utilities, notebooks) must be handled with targeted per-file-ignores
rather than wholesale exclusions. This prevents masking real violations while avoiding
false positives.

Pattern:
1. Add rule to `select` list in `[lint]` section
2. Run full `ruff check .` to surface all violations
3. Categorize violations: `src/` violations must be fixed; other legitimate uses get per-file-ignores
4. Add specific per-file-ignores with comments explaining why each exclusion is legitimate

## Pattern: logging Module Integration

When replacing `print()` with `logging` in a module:
1. Add `import logging` after stdlib imports
2. Add `_logger = logging.getLogger(__name__)` at module level (after imports, before helpers)
3. Replace `print(msg)` with `_logger.warning(msg)` or appropriate level
4. Tests should verify: `_logger` attribute exists, logger name matches `__name__`, logging imported
