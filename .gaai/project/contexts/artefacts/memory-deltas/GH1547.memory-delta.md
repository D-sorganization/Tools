# Memory Delta: GH1547

## New Patterns Worth Persisting

### CI Pattern: Always-On Provider-Contract Step

When a repo exposes a shared library with downstream consumers, the CI `tests` job
should include an unconditional step (no `if:` gate) that runs the exported-package
test suites with:
- Explicit test directory targeting (not relying on changed-file detection)
- `--cov-fail-under=<N>` (N ≥ 10, not 0)
- `--cov-report=term` for visibility
- `$GITHUB_STEP_SUMMARY` entry for GitHub UI visibility

This pattern was established in GH1547 for `upstream_drift_tools`, `signal_toolkit`,
`model_generation`, and `theme`.

### Coverage Gate Calibration

The 10% coverage floor is sufficient for the provider-contract step because:
- The step's primary purpose is import verification and API-surface regression detection
- Full unit coverage is handled by the main test suite
- Actual measured coverage was 25.5%, well above the gate

No new services, paradigm shifts, or stack additions. Pure CI configuration change.
