# GH1702 Memory Delta

## Pattern: Targeted noqa over Global Suppression

When removing a global lint rule suppression reveals pre-existing violations
across many files, the correct delivery scope is:

1. Remove the global suppression (the actual fix)
2. Add `# noqa: <RULE>` only to lines in **modified files** that cannot be shortened
3. Document pre-existing violations for a follow-up story

Do NOT attempt to fix all pre-existing violations in the same story — this
would expand scope beyond the acceptance criteria.

## Finding: Pre-Existing E501 Debt

As of 2026-03-22, `src/` contains 438 E501 violations across 115+ files
that were hidden by the now-removed global suppression. A dedicated cleanup
story should address these systematically, likely with `ruff --fix` where possible.

## Config Pattern

```toml
# ruff.toml — correct pattern after GH1702
# Global suppression removed. Use targeted noqa on specific lines:
#   some_long_string = "..."  # noqa: E501
```
