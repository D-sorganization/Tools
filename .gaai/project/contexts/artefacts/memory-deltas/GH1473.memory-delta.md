# GH1473 Memory Delta

## New Pattern: Headless PyQt6 Testing with Real Base Class Stub

**Context:** Tests for PyQt6 window classes that inherit from a custom base (e.g., `BaseCalculatorWindow`) require a real stub base class, not just a `MagicMock`, because Python class definitions inherit the mocked type when the base is a MagicMock.

**Pattern:**
```python
class _FakeBaseCalculatorWindow:
    def __init__(self, ...): self.main_layout = MagicMock()

base_calc_mock = MagicMock()
base_calc_mock.BaseCalculatorWindow = _FakeBaseCalculatorWindow
```
Then use `patch.dict(sys.modules, {..., 'module.base': base_calc_mock})` and load via `importlib.util.spec_from_file_location`.

**Trigger:** Any test loading a PyQt6 widget class that inherits from a project-defined base class.

## New Pattern: DbC for GUI Methods

**Context:** GUI methods called by Qt signal handlers receive values from Qt widgets (always valid floats/strings from the UI). However, for API robustness, DbC preconditions should use `math.isfinite()` for float validation and `isinstance()` for type checking, not `assert`.

**Standard:**
```python
for name, val in (("param", param), ...):
    if not isinstance(val, (int, float)):
        raise TypeError(f"{name} must be a numeric value, got {type(val).__name__}")
    if not math.isfinite(val):
        raise ValueError(f"{name} must be a finite number, got {val}")
```
