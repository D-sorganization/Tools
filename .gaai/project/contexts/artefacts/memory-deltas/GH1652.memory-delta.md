# GH1652 Memory Delta

## Pattern: Shared @deprecated Decorator

**Context:** Tools is a shared library consumed by UpstreamDrift and Gasification_Model.
A production-quality `@deprecated` decorator was added to `src/shared/python/deprecation.py`.

**Pattern:**
```python
from deprecation import deprecated

@deprecated(reason="Use new_func() instead.", removal_version="2.0.0")
def old_func(x: float) -> float:
    ...
```

**Key design decisions:**
- Uses `warnings.warn(..., DeprecationWarning, stacklevel=2)` — stacklevel=2 ensures
  the warning points to the call site, not the decorator internals
- Uses `functools.wraps` to preserve `__name__`, `__doc__`, and all metadata
- Validates `reason` (must be str) and `removal_version` (must not be empty) at
  decoration time, not call time — fails fast
- `removal_version=None` is the default (no version text emitted)

**Versioning baseline:** The canonical package version is now `1.0.0` (pyproject.toml).
All internal `__version__` strings should align to this when updated.
