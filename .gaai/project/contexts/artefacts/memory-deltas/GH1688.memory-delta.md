# GH1688 Memory Delta

## Pattern: pytest.importorskip() for optional heavy dependencies

When tests depend on optional packages (trimesh, ezdxf, PyQt6, etc.) that may not be installed in all environments, use `pytest.importorskip()` at the beginning of each test method rather than a bare `import`. This converts `ModuleNotFoundError` FAIL into SKIP, which is the correct outcome when the dep is genuinely optional.

```python
def test_some_contract(self) -> None:
    trimesh = pytest.importorskip("trimesh", reason="trimesh not installed")
    # rest of test uses local trimesh variable
```

## Pattern: Module-level logger placement

When adding logging to an existing module, place `_logger = logging.getLogger(__name__)` after all imports (including local package imports) to avoid E402 (module-level import not at top of file) ruff violations.

```python
import logging
import math

import numpy as np

from mypackage._contracts import require  # local import

_logger = logging.getLogger(__name__)  # after ALL imports
```
