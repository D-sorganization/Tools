# GH1493 Memory Delta

## Pattern: Dual-Copy Module Sync via Test

`src/urdf_builder_gui` uses a dual-directory layout (`root/` and `python/urdf_builder_gui/`) for
package discovery compatibility. The `TestFileSyncIntegrity` test class enforces that both copies
stay identical by reading and comparing file contents at test time. This is a reusable pattern for
any module that must exist in two locations.

## Pattern: LoD Assessment for `pathlib.Path` Chains

`Path(__file__).resolve().parent / "python"` is a fluent chain on the same `Path` object — not a
Law of Demeter violation. When assessing LoD, distinguish between:
- Chains that traverse through foreign objects (violations)
- Fluent chains on the same object (acceptable)

## Pattern: DbC with Clamping Instead of `require()`

`interpolate_gender_factor` uses `max(0.0, min(1.0, factor))` to enforce range constraints. This
is a valid DbC pattern for numeric range enforcement that is self-correcting rather than
fault-raising — appropriate when the caller's intent is unambiguous and silent correction is
preferred.
