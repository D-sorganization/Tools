# GH1696 Memory Delta

## Patterns Worth Persisting

### Lazy Import Convention for Large __init__.py Files

**Pattern**: Use `_LAZY: dict[str, tuple[str, str]]` + `__getattr__` for large `__init__.py` re-export files.

**Established instances**:
- `data_processor/core/__init__.py` — issue #530
- `model_generation/__init__.py` — issue #611
- `signal_toolkit/__init__.py` — issue #1696 (this delivery)

**Template**:
```python
_LAZY: dict[str, tuple[str, str]] = {
    "ClassName": (".submodule", "ClassName"),
}

def __getattr__(name: str) -> Any:
    if name in _LAZY:
        mod = importlib.import_module(_LAZY[name][0], package=__name__)
        value = getattr(mod, _LAZY[name][1])
        globals()[name] = value  # cache
        return value
    raise AttributeError(f"module {__name__!r} has no attribute {name!r}")
```

**Caveat**: Optional GUI imports (try/except PyQt6) must remain eager if `HAS_*` flags need to be synchronously resolvable. If the GUI module transitively imports heavy submodules, the lazy-loading benefit is only realized in non-PyQt6 environments.

### Legacy Code Extraction Pattern

**Pattern**: When an `__init__.py` contains actual implementation code (classes, functions, constants), extract to a `_legacy.py` module and re-import from there.

**Naming convention**: `_legacy.py` (underscore prefix = internal, not part of public API).

**Documentation**: Add a section header comment in `__init__.py`:
```python
# LEGACY API - Backwards Compatibility
# Extracted to _legacy.py (issue #NNNN — god module refactor)
from ._legacy import SymbolA, SymbolB
```
