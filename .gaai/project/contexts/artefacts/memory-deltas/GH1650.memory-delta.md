# GH1650: Memory Delta

## New Patterns Observed

### Pattern: Algorithm phase extraction for iterative algorithms

When an algorithm has distinct forward/backward (or init/propagation) passes, extract
each phase as a private module-level helper. This:
- Makes each phase independently testable
- Reduces the public function to an orchestrator
- Preserves the public API

Applied in: `InverseDynamics` → `_inverse_dynamics_forward_pass` + `_inverse_dynamics_backward_pass`

### Pattern: Wide-signature public functions — docstring vs. body length

Functions with >15 typed parameters will always exceed 50L from their signature alone.
The team convention targets implementation complexity, not parameter count or docstring length.
When a function body is already clean delegation (<15L), the refactoring goal is met even
if total line count remains above 50L.

## No Architectural Decisions

No new architectural decisions. All changes are mechanical refactoring within existing modules.
