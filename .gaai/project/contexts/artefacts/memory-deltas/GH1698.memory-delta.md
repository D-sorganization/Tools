## Notable Pattern: RUF100 --extend-select vs --select

A process pattern worth noting for future noqa audits:

**Pattern:** When removing stale `# noqa` suppressions with ruff:
- Use `ruff check --extend-select RUF100 --fix` (NOT `--select RUF100 --fix`)
- `--select` replaces the entire configured ruleset, causing false positives
- `--extend-select` adds RUF100 on top of the project's configured rules

This ensures only genuinely unused suppressions (for non-enabled rules) are removed.
