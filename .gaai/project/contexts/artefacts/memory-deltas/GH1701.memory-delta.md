# GH1701 Memory Delta

## New Patterns / Decisions Worth Persisting

### Pattern: Coverage Enforcement Architecture

**Finding:** The project uses a two-tier coverage enforcement system:
1. `[tool.coverage.report] fail_under` in `pyproject.toml` — applies to local `pytest --cov` runs
2. `config/coverage_policy.json` + `scripts/check_coverage_policy.py` — applied by CI with `--cov-fail-under=0` override

These values were divergent (40% vs 28%). When modifying coverage thresholds, **both files must be updated together**.

**Suggested memory entry:** Add to `patterns/conventions.md`:
> Coverage thresholds live in two places: `pyproject.toml` (local dev) and `config/coverage_policy.json` (CI enforcement). Always update both when changing thresholds.

### Pattern: Marker Registration Requirement

**Finding:** With `--strict-markers` enabled in `addopts`, all markers used in tests or referenced in CI commands must be declared in `[tool.pytest.ini_options] markers`. Previously 9 of 13 canonical markers were missing.

**Suggested memory entry:** When adding new test markers, register them in `pyproject.toml` `[tool.pytest.ini_options] markers` or tests will fail with `--strict-markers`.

## No Architectural Decisions

All changes were implementation-level config fixes. No new architectural decisions required escalation to Discovery.
