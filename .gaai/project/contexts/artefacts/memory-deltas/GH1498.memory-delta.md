# GH1498 Memory Delta

## Pattern: Eliminating LoD Violations in Mock Setup

**Context:** Python `unittest.mock.MagicMock` objects encourage multi-level attribute chains like `mock.method.return_value = X`, which violates the project's Law of Demeter rule (no chains >2 levels).

**Solution:** Use `mock.configure_mock(**{"method.return_value": value})` — the dotted keys are dictionary strings, not Python attribute access, so they do not violate LoD.

**Applicable to:** Any test fixture that configures mock return values.

## Pattern: DbC Preconditions in Test Helpers

**Context:** Test helper functions with arguments (like `assert_monotonic`) should apply the same DbC standards as `src/` code — explicit `isinstance` checks raising `TypeError` for wrong argument types.

**Signal:** Low (one-off — apply when writing new test helpers).
