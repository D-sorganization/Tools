# GH1689 Memory Delta

## Pattern: Single Authoritative Config for Ruff

When ruff.toml and pyproject.toml [tool.ruff] coexist, ruff.toml takes precedence.
Remove [tool.ruff] from pyproject.toml and keep ruff.toml as the single source of truth.

## Pattern: Tests Must Reference Authoritative Config File

Tests asserting on ruff settings (e.g. T201 in select) must read from the file that
ruff actually uses (ruff.toml), not a secondary config that gets overridden.

## Pattern: T201 Suppress List for This Repo

Files where T201 (print-statement) is legitimately suppressed:
- `scripts/**/*.py` and `scripts/*.py` — CLI scripts
- `*.py` (root-level) — launcher and utility scripts
- `**/*.ipynb` — Jupyter notebooks (excluded from scanning AND per-file-ignore)
