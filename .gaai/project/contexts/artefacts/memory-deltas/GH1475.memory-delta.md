# GH1475 Memory Delta

## Memory Alignment Check

### New Patterns Worth Persisting

**Pattern: DbC in PyQt6 GUI methods**
The standard pattern for DbC in GUI methods that process data (not UI setup methods)
is to use `isinstance` checks raising `TypeError` at the top of the method.
UI setup methods (`_setup_ui`, `_create_*_tab`) do not need preconditions because
their inputs are always from `self` attributes set by Qt.

**Pattern: LoD for Qt constant chains**
Deep Qt constant chains (`Qt.ScrollBarPolicy.X`, `Qt.AlignmentFlag.X`,
`QSizePolicy.Policy.X`) should be extracted to module-level aliases when used in
class methods. Signal connection chains (`btn.signal.connect(handler)`) should
be split into two statements.

### No New Architecture Decisions

This delivery follows established patterns. No architectural decisions were made.
