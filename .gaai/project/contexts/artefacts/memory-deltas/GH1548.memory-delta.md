# GH1548 Memory Delta

## New Patterns Worth Persisting

### Pattern: `_skip_no_X` skip marker for optional dependencies

**Domain:** test infrastructure / pytest patterns

**Convention:**
```python
def _X_available() -> bool:
    try:
        import X  # noqa: F401
        return True
    except ImportError:
        return False

_skip_no_X = pytest.mark.skipif(not _X_available(), reason="X not installed")
```

Use `@_skip_no_X` as a test/class-level decorator instead of inline `pytest.importorskip()` inside test
bodies or inside `skipif` condition expressions.

**Rationale:** `pytest.importorskip()` inside `skipif(not ...)` is semantically incorrect (raises instead
of evaluating). The helper function pattern is idiomatic, statically analyzable, and composable.

**Applicable when:** Any test that guards on an optional dependency (matplotlib, pyarrow, etc.)

---

### Pattern: Isolate non-Qt tests from Qt-gated test files

**Domain:** test infrastructure / PyQt6 / headless CI

**Convention:** When a source module imports Qt at module level but contains functions with no runtime Qt
dependency, create a separate test file (e.g., `test_X_helpers.py`) that:
1. Uses `pytest.importorskip("PyQt6")` (not `PyQt6.QtWidgets`) as the gate
2. Contains only tests for the pure-Python subset
3. Documents that the test would be dependency-complete once the helpers are moved to a pure module

**Rationale:** This separation makes headless-safe tests visible and clearly scoped, reduces confusion
about what tests actually need a display server.
