# GH1485 Memory Delta

## Memory Alignment Check Result

No significant memory drift detected. The delivery confirmed and applied established conventions.

## Patterns Confirmed

### Test Infrastructure Pattern (Tools_Private)
- Each embedded `src/*/tests/` module should have a `conftest.py` that adds the `python/` subdirectory to sys.path.
- The established pattern is documented in `electrode_advisor/tests/conftest.py`.
- `scrubber_calculator/tests/conftest.py` now follows this pattern.

### Optional Dependency Skip Pattern (Tools_Private)
- Tests depending on `upstream_drift_tools` (which lives in the Tools repo, not Tools_Private) should use try/except → pytest.skip.
- The established pattern is in `syngas_water_calculator` tests.
- `glass_bath_fea/tests/conftest.py` uses the same pattern for the `ensure_paths` call.
- This ensures CI passes without the Tools repo present.

## New Patterns Worth Persisting

**Pattern: Exception broadening in dynamic module loading**

When using `importlib.util.spec_from_file_location` + `exec_module()` to dynamically load optional modules, catch `(ImportError, FileNotFoundError, OSError)` — not just `ImportError`. `FileNotFoundError` occurs when the module file doesn't exist (path points to a different repo's file), `OSError` covers permission issues.

This pattern was applied in `test_scrubber_calculator_gui.py:load_scrubber_module()`.

## Memory Ingest Recommendation

- Consider adding the "optional dependency skip pattern" to `conventions.md` if it doesn't already exist, as it applies to all Tools_Private embedded test modules.
- The `conftest.py` pattern for embedded tests should be part of the project template.
