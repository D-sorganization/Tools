# GH1733 Memory Delta

## Memory Alignment Check

### New Patterns Worth Persisting

**Pattern: Tiered Dependency Pinning for Shared Libraries**

- `pyproject.toml` runtime deps: use `>=` minimum bounds (correct for libraries — do NOT change to ==)
- `requirements.txt` dev env: use `>=` bounds, paired with `requirements-lock.txt` for reproducibility
- `requirements-lock.txt`: exact `==` pins, regenerated at sprint start or after requirements.txt changes
- Sub-module app requirements: use `>=` minimum bounds at minimum; never leave packages completely unpinned
- `tkinter` and other stdlib modules: comment out from pip requirements files with explanation

**Pattern: Policy Documentation First**

When introducing a pinning or versioning strategy, write the policy document (`DEPENDENCIES.md`)
first, then update the files to comply. This ensures the rationale is captured before the
mechanical changes obscure it.
