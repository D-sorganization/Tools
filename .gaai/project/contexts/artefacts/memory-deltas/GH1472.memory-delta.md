# Memory Delta: GH1472

## Pattern: PyQt6 LoD Enum Alias Convention

**Context:** PyQt6 uses deeply nested enum namespaces (e.g., `Qt.ScrollBarPolicy.ScrollBarAlwaysOff`, `QHeaderView.ResizeMode.Stretch`). These 3-level chains violate the Law of Demeter.

**Established pattern:** Define module-level private aliases (prefixed `_`) immediately after imports, then use the aliases throughout the module:

```python
_SCROLL_BAR_ALWAYS_OFF = Qt.ScrollBarPolicy.ScrollBarAlwaysOff
_ALIGN_CENTER = Qt.AlignmentFlag.AlignCenter
_HORIZONTAL = Qt.Orientation.Horizontal
# ... etc
```

**Note:** PyQt6 signal `.connect()` calls (`widget.signal.connect(handler)`) are NOT LoD violations — they are standard signal/slot patterns and should not be flagged.

**Applies to:** All PyQt6 GUI modules in the codebase.
