# GH1489 Memory Delta

## Pattern: Testing PyQt6 modules with spec_from_file_location

When a PyQt6 module uses top-level enum chains (LoD violations) and needs to be
tested headlessly, `importlib.util.spec_from_file_location` is more reliable than
`patch.dict(sys.modules)` + package import, because:

1. The package's installed path may not expose the `ui/` subdirectory
2. Module caching can prevent re-import under new mocks
3. `spec_from_file_location` loads the file directly, bypassing package resolution

The `_FakeBaseCalculatorWindow` stub (plain Python class with `**kwargs` init)
allows `object.__new__(cls)` + attribute assignment to work cleanly, avoiding
the MagicMock `__setattr__` interception problem when the parent class is mocked.

## Pattern: Module-level enum aliases for Qt LoD compliance

PyQt6 enum chains (`Qt.ScrollBarPolicy.ScrollBarAlwaysOff`, `QSizePolicy.Policy.Expanding`)
are 3-level accesses that violate LoD. The established convention (used in
thermal_profile_predictor, syngas_water_calculator) is to define module-level
private aliases using `_UPPER_SNAKE_CASE` naming immediately after imports.
