# Memory Delta: GH1653

## Pattern: Cross-Repo Import Compatibility Tests

When creating integration tests that verify downstream repo compatibility:

1. Use `@pytest.mark.integration` marker (registered in pyproject.toml)
2. Place tests in `tests/test_cross_repo_import_compatibility.py`
3. Test both direct symbol imports (`from pkg import Symbol`) and subpackage
   importability (`importlib.import_module("pkg.subpackage")`) separately —
   subpackage names in `__all__` are not bound as module attributes until
   explicitly imported
4. Test both happy paths and error paths for validator methods
5. Protocol runtime-checkability verification via `isinstance(plain, Proto)` —
   must not raise TypeError

## Key Finding

`upstream_drift_tools.__all__` lists subpackage names for documentation, but they
are NOT bound as module-level attributes without explicit import. Tests must guard
for this distinction.
