# GH1651 Memory Delta

## Pattern: hashlib.md5 with usedforsecurity=False

When MD5 is used for non-security purposes (e.g., content checksums, cache
keys, version fingerprints), always pass `usedforsecurity=False` to
`hashlib.md5()`. This:

1. Resolves Bandit S324 HIGH-severity findings
2. Allows execution on FIPS-enforcing platforms
3. Documents the non-security intent explicitly in code

Search the codebase for other `hashlib.md5(` or `hashlib.sha1(` calls that
lack `usedforsecurity=False` and apply the same pattern.
