# GH1495 Memory Delta

## Summary

No new architectural or governance decisions emerged. Standard LoD remediation pattern applied.

## Pattern: Testing build123d-dependent modules

`build123d` is an optional CAD library imported at module-level in several `vessel_drafter`
modules. When testing these modules without the real library, a `MagicMock()` stub must be
placed in `sys.modules["build123d"]` before any vessel_drafter import occurs.

Additionally, `src/vessel_drafter/__init__.py` (shallow wrapper) conflicts with
`src/vessel_drafter/python/vessel_drafter/` (real package) when pytest's `pythonpath = src`
is processed first. Resolution: place `src/vessel_drafter/python` before `src` in `pytest.ini`
pythonpath and add stale module cache eviction in the test conftest.

Candidate for `contexts/memory/patterns/conventions.md` entry under "Testing optional CAD
dependencies".
