# GH1481 Memory Delta

## No New Durable Decisions

This delivery applied established LoD and DbC patterns that are already documented conventions. No new architectural or governance decisions were made.

## Pattern Observations

**LoD fix pattern for chained method calls on standard library objects:**
- `sys.stderr.write()` → `stderr = sys.stderr; stderr.write()`
- `importlib.util.find_spec()` → `from importlib.util import find_spec; find_spec()`
- `path.suffix.lower()` → `suffix = path.suffix; lower_suffix = suffix.lower()`

These patterns are consistent with existing conventions in the codebase.

**Test directory naming convention for excluded modules:**
`project_packer` is in `norecursedirs` in pytest.ini. Tests for this module should be placed in a directory named `project_packer_fixes` (or similar non-excluded name) in `tests/`.
