# GH1699 Memory Delta

## Patterns Worth Persisting

### pytest.importorskip for optional heavy deps
Heavy integration tests for optional deps (trimesh, ezdxf, PyQt6) should use
`pytest.importorskip("dep_name", reason="...")` at the test body level rather
than bare `import dep_name`. This converts ImportError collection failures into
graceful skips, keeping the CI green on environments without those deps.

### Gasification_Model integration test pattern
The cross-repo test file should cover both consumers: UpstreamDrift patterns (existing)
and Gasification_Model patterns (process_calculators subpackage). The distinction
matters because Gasification_Model uses process_calculators symbols that UpstreamDrift
does not, creating an invisible blind spot in the original test suite.

### contracts.py DbC API surface — contract marker
Tests that verify contracts.py `require`/`ensure`/`precondition` behaviour should
be marked `@pytest.mark.contract` (not just `integration`), since downstream consumers
(Gasification_Model) depend on these raising PreconditionError/PostconditionError
at the correct level.
