# Memory Delta: GH1656

## Pattern: Cross-Platform Thread-Based Timeout

**Context:** ODE solver and other long-running computations need timeout guards.

**Decision:** Use `threading.Thread(daemon=True)` + `thread.join(timeout=N)` rather than `signal.SIGALRM`. Reason: `signal.SIGALRM` is UNIX-only and incompatible with pytest-xdist `-n auto` parallel workers.

**Pattern established in:** `src/ode_solver/python/ode_solver/timeout.py`

**Key properties:**
- DbC guards on `with_timeout()`: TypeError for wrong types, ValueError for non-positive seconds
- Daemon threads: abandoned on timeout, no OS resource leak
- Exception propagation: worker exceptions re-raised in caller thread
- `SolverTimeoutError(TimeoutError)`: public exception for clear `except` clauses

## Pattern: Performance Test Conventions

**Existing pattern confirmed:** Use `time.perf_counter()` wall-clock timing for load tests, not pytest-benchmark directly. Mark with `@pytest.mark.slow @pytest.mark.performance`. Skip with `pytest.skip()` if optional dependencies unavailable. Consistent with `test_syngas_water_overflow.py`.
