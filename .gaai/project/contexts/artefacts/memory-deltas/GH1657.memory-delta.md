# Memory Delta: GH1657

## Pattern: XDG Base Directory for config paths

When adding user config directories, use `get_xdg_config_dir(app_name)` from
`src/python/src/utils/config_loader.py` instead of hardcoding `Path.home() / ".appname"`.

The function handles:
- Linux/macOS: `$XDG_CONFIG_HOME/<app_name>` (fallback: `~/.config/<app_name>`)
- Windows: `%APPDATA%/<app_name>` (fallback: `~/.config/<app_name>`)

The function does NOT create the directory — callers must call `.mkdir(parents=True, exist_ok=True)`.

## Convention: Log files for GUI tools

GUI tools (folder_tool pattern) should use `_get_log_path()` to derive log file
location, rather than writing to CWD. See `src/folder_tool/Folders_Tool_r0.py`.
