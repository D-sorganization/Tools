# GH1476 Memory Delta

## Patterns Worth Persisting

### PyQt6 LoD Fix Pattern

When PyQt6 code uses `Qt.EnumClass.EnumValue` (3-level chain), the canonical fix is module-level aliases:

```python
# At module level — breaks LoD, no performance cost
_SCROLL_BAR_OFF = Qt.ScrollBarPolicy.ScrollBarAlwaysOff
_ALIGN_CENTER = Qt.AlignmentFlag.AlignCenter
```

For signal connection chains (`obj.signal.connect(...)`), use a local variable:
```python
signal = obj.signal
signal.connect(handler)
```

### Testing PyQt6 Methods Without QApplication

Unbound PyQt6 instance methods whose preconditions execute before any Qt interaction can be tested via `MagicMock(spec=TargetClass)`:

```python
mock_self = MagicMock(spec=ODESolverWindow)
ODESolverWindow._parse_dict_input(mock_self, text)
```

This avoids requiring a live `QApplication` and display in CI.

### DbC Convention Reminder

`assert` is wrong for DbC in production code — it's disabled by `python -O`. Always use explicit `raise TypeError` / `raise ValueError` with descriptive messages.
