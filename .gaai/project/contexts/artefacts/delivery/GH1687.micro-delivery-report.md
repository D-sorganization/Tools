## Change Summary

Two independent root causes were fixed:

1. **folder_tool (11 errors)**: `src/folder_tool/archive_ops.py` imports `Folders_Tool_r0` at module
   level. The `src/folder_tool/` directory was missing from pytest.ini `pythonpath`. Adding it
   allows `Folders_Tool_r0` to resolve, fixing all 11 collection errors.

2. **programmatic_pid (16 errors)**: `ezdxf` is an optional dependency not installed in CI.
   `programmatic_pid/__init__.py` transitively imports `ezdxf` via `cli.py`, so any import of
   `programmatic_pid.*` fails at collection time. Adding `pytest.importorskip("ezdxf")` before
   programmatic_pid imports in all 16 test files converts hard collection failures into graceful
   skips.
