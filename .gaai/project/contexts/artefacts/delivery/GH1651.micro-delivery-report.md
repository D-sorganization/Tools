# GH1651 Micro-Delivery Report

## Story

**Title:** Fix MD5 weak hash finding in text_editor.py:796
**Tier:** 1 (MicroDelivery — single-line fix, 1 file affected)

## Change Summary

Added `usedforsecurity=False` to the `hashlib.md5()` call in
`URDFTextEditor._add_to_history()`. MD5 is used exclusively for non-security
version-history checksums; the flag makes the intent explicit and resolves the
Bandit S324 HIGH-severity finding. The fix also allows the code to execute
correctly on FIPS-enforcing platforms.
