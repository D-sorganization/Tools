## Design Decisions

1. **Why not refactor all 7 god classes?** GUI classes (DataProcessorWidget,
   ProcessingMixin) require `pytest-qt`/PyQt6 display for testing and cannot be
   safely refactored without test coverage. DataProcessorEngine and DataProcessor share
   `self.data` state — mixin extraction creates hidden coupling. The CI guard is the
   correct enforcement mechanism.

2. **Why private sub-mixins?** The `_` prefix signals these are implementation details.
   `CalculatorStateMixin` remains the stable public API. Downstream callers (UpstreamDrift,
   Gasification_Model) import `CalculatorStateMixin` only — zero breaking changes.

3. **`# type: ignore[attr-defined]`** used in sub-mixins where they reference `self.splitters`,
   `self.change_tracking_enabled` etc. — attributes initialized in `CalculatorStateMixin.__init__`.
   This is the established pattern for non-QObject mixins (same as original).
