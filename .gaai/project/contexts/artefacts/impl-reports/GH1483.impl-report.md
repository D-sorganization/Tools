# GH1483 Implementation Report

## Summary

- Replaced all bare `assert x is not None` preconditions in three `src/rotation_converter/` modules with explicit `raise TypeError(...)` guards that are not disabled by Python's `-O` flag.
- Fixed one Law of Demeter violation in `Rotation.compose` by replacing `other._q` (private attribute access) with the public `other.as_quaternion()` method.
- Added 13 new DbC precondition tests verifying `TypeError` is raised (not `AssertionError`), and one regression test verifying `compose` correctness after the LoD fix.
