# GH1701 Implementation Report

## Summary

Three configuration changes address the Tracer Bullets finding: inconsistent coverage threshold, missing pytest markers, and undocumented contract test enforcement.

## Changes Delivered

| File | Change | Purpose |
|------|--------|---------|
| `pyproject.toml` | `fail_under = 40` → `30` | Align local coverage gate with actual measured coverage (31.37%); previous value was misleading |
| `pyproject.toml` | Added 10 markers to `[tool.pytest.ini_options]` | Register all 13 markers from CLAUDE.md spec; `--strict-markers` was enabled but 9 markers were undeclared |
| `config/coverage_policy.json` | `minimum_total_percent: 28.0` → `30.0` | Tighten enforced floor toward actual baseline; CI uses this file, not pyproject.toml |
| `.github/workflows/ci-standard.yml` | Added comment to Provider-Contract Suite step | Document that contract tests run unconditionally on every PR |

## Key Finding

The `fail_under = 40` in `pyproject.toml` was **never enforced by CI** — the CI test step passes `--cov-fail-under=0` and delegates to `scripts/check_coverage_policy.py`. The effective enforcement was `minimum_total_percent: 28.0` in `config/coverage_policy.json`, well below the actual baseline of 31.37%.
