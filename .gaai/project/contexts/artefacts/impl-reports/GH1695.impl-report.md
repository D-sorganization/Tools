## Key Technical Note

When the same `.py` file is imported via two different module paths
(`contracts` vs `src.shared.python.contracts`), Python creates two separate module
objects with different class identities. This means `pytest.raises(PreconditionError_A)`
will NOT catch `PreconditionError_B` even though they are from the same source file.

The import standardization in both `src/` AND `tests/` was required to maintain
module-identity consistency. Files left using the absolute path were ones where:
1. The function being tested comes from UpstreamDrift via symlink (uses absolute path internally)
2. OR the file is in a sub-project with its own sys.path setup (`data_processor/contracts.py`)
