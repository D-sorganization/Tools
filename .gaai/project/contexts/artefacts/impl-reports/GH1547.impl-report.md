# Implementation Report: GH1547

## Summary

Added a dedicated "Provider-Contract Suite (Exported Packages)" step to the `tests`
job in `.github/workflows/ci-standard.yml`. The step always runs (unconditional, no
`if:` gate), collecting and executing the full test suites for the four core exported
packages: `upstream_drift_tools`, `signal_toolkit`, `model_generation`, and `theme`.

- Explicitly targets `tests/shared/python/upstream_drift_tools/`, `tests/shared/python/signal_toolkit/`, `tests/shared/python/model_generation/`, `tests/shared/python/theme/`
