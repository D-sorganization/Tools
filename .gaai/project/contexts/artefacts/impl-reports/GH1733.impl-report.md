## Key Decision

`pyproject.toml` runtime dependencies intentionally retain `>=` bounds — this is correct for
a shared library. Pinning to `==` in pyproject.toml would break compatibility for downstream
consumers (UpstreamDrift, Gasification_Model). The lock file strategy handles reproducibility
without constraining the library surface.
