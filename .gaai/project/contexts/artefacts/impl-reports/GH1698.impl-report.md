# GH1698 Implementation Report — noqa Suppression Audit

## Summary

- Removed 90 stale `# noqa` suppressions from 62 files in `src/` using `ruff check --extend-select RUF100 --fix`
- All removed suppressions were for rule codes not enabled in the project's ruff configuration
- No logic changes made — all changes are comment removals only
- 1 pre-existing format issue in `src/asteroid_jumper/physics.py` fixed as part of the changes

## Implementation Notes

### Approach Correction During Execution

Initial attempt used `ruff check src/ --select RUF100 --fix`. This was incorrect: `--select` replaces the
entire rule set, making E/F/W rules "non-enabled" and thus all their noqa directives appear stale.

Correct approach: `ruff check src/ --extend-select RUF100 --fix`. This adds RUF100 on top of the
project's configured rules (E, F, W, I, B, UP), ensuring only genuinely unused suppressions are removed.

Result: 90 stale suppressions removed (not 183 as initially misdiagnosed).

### Stale Suppression Categories

The removed suppressions fell into these categories:
- `PYI034` — rule not in selected ruleset (PYI = flake8-pyi, not enabled)
- `N802`, `N806` — naming convention rules (N = pep8-naming, not enabled)
- `S101`, `S603`, `S606`, `S607`, `S104` — security rules (S = flake8-bandit, not enabled)
- `E402` suppressions where the import was NOT actually after non-import code (false suppressions)
- `F401` suppression in a test file where the import was being used
- Various other rule codes from rule sets not in `select`
