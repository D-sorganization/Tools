**Note on line 12 LoD:** `os.environ.get("HEADLESS", "false").lower()` is a 3-level chain. Fixing it via a module-level assignment (`_headless_env = os.environ.get(...)`) triggers ruff E402 on all subsequent imports. The established codebase pattern (identical pattern in `src/function_generator/python/function_generator/ui/pyqt6/main_window.py`) treats this `if os.environ.get(...)` conditional guard as acceptable. Fixing line 12 would require adding `# noqa: E402` to all subsequent imports, which is a larger scope change and creates inconsistency with the `function_generator` module. Left as-is to maintain ruff compliance (AC3).
