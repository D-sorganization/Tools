# GH1548 Implementation Report: Audit and Reduce Skip-Heavy Shared-Package Tests

## Summary

- Audited all `skip`/`xfail`/`importorskip` usage across `tests/shared/python/`
- Identified 3 skip-debt instances and 8 legitimate optional skips
- Eliminated 3 skip-debt issues via targeted test restructuring
- Documented remaining optional skips in a persistent register

| File | Change Type | Purpose |

| `tests/shared/python/chat/test_chat_session_helpers.py` | **Created** | Extracted `TestSessionFileHelpers` from `test_chat_dock_widget.py`; session-file helper tests isolated and clearly scoped to `importorskip("PyQt6")` only (not `PyQt6.QtWidgets`) |

## Known Limitations

- The `TestSessionFileHelpers` in the new file still requires `importorskip("PyQt6")` because the
  session helper functions live in `chat_dock_widget.py` which imports PyQt6 at module level.
  True elimination of the PyQt6 dependency would require extracting the helpers to a separate
  pure-Python module — this is tracked in the skip-debt register as residual debt.
