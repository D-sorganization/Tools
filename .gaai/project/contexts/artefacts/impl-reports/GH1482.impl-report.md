## Summary

## Detail: performance_utils.py

**DbC changes:**
- `OptimizedFileScanner.__init__`: replaced `assert max_workers is not None` with `isinstance(max_workers, int)` check → `TypeError`, and `max_workers < -1` check → `ValueError`
- `scan_directory_parallel`: replaced `assert root_path is not None` with `isinstance(root_path, Path)` check → `TypeError`
- `scan_subdirectory` (nested): replaced `assert directory is not None` with `isinstance(directory, Path)` check → `TypeError`

**LoD changes:**
- Lines 60 and 120: `os.path.getmtime(root_path)` → `root_path.stat().st_mtime` — root_path is already a `Path` object, so `.stat().st_mtime` is a 2-level chain vs the 3-level `os.path.getmtime`

## Detail: plugin_manager.py

**DbC changes:**
- `PluginManager.__init__`: replaced `assert repo_root is not None` with `isinstance(repo_root, Path)` check → `TypeError`
- `get_tool_by_name`: replaced `assert name is not None` with `isinstance(name, str)` check → `TypeError`

**LoD changes:**
- Extracted `manifest_dir = manifest_path.parent` variable before use; replaced `manifest_path.parent.name` and `manifest_path.parent.glob(...)` with `manifest_dir.name` and `manifest_dir.glob(...)` — resolves 3-level chains at lines 163, 167, and 197
