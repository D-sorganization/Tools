## Implementation Details

### __init__.py Pattern Change

The `no-redef` mypy errors arose because variables were annotated in the `except`
branch after being imported without annotation in the `try` branch. The fix:

1. Pre-declare variables with type annotations BEFORE the try/except
2. Use `import X as X` in the try branch (Python's re-export syntax)
3. In the except branch: only append to `_import_errors` (no reassignment needed)

This eliminates 6 `no-redef` ignores and 3 `assignment`/`misc, assignment` ignores.

### psa_gui.py Fix

`ax.plot_surface()` and `ax.set_zlabel()` raise `attr-defined` errors because
matplotlib's 3D Axes (`Axes3D`) stubs don't expose these methods in all environments.
The fix: annotate `ax` as `Any` immediately after `add_subplot(111, projection="3d")`.
This is the idiomatic approach for Axes3D usage, matching the `[mypy-..analysis_tab]
warn_unused_ignores = False` pattern already in mypy.ini for pendulum_simulator.

### mypy.ini Cleanup

1. `electrode_advisor/python/electrode_advisor/` — directory does not exist in this repo
2. `media_processing/video_processor/python/src/` — 1 Python file, passes mypy cleanly

## Remaining type: ignore (8 of 20)

The 8 remaining ignores are all legitimate:

  optional PyQt6 imports
- 1 in `wgs_reactor_calculator.py`: BaseCalculatorWidget fallback class
- 2 in `acid_gas_dewpoint_calculator.py`: BaseCalculatorWidget fallback + dynamic
  base class

These cannot be removed without either (a) restructuring the try/except import pattern
significantly or (b) using mypy.ini module-level overrides, which would reduce
visibility rather than fix the root issue.
