# GH1495 Implementation Report

- Resolved all remaining LoD violations in `src/vessel_drafter` by extracting
  intermediate attribute accesses into local variables.

## Friction Log

- `build123d` is an optional CAD library imported at module-level in several
  `vessel_drafter` modules. Required a `MagicMock` stub in `conftest.py`.
- `src/vessel_drafter/__init__.py` (shallow wrapper) conflicts with
  `src/vessel_drafter/python/vessel_drafter/` (real package) when pytest's
  `pythonpath = src` is processed first. Resolved with module cache eviction
  in `tests/vessel_drafter/conftest.py` and by placing the correct path first
  in `pytest.ini`.
