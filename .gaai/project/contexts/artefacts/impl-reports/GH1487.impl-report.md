# GH1487 Implementation Report

## Summary

- Fixed 4 DbC violations in `signal_bus.py` by replacing `assert` statements with explicit `ValueError`/`TypeError` guards, and added preconditions to `__init__`

- Added 10 new tests covering all preconditions

## Changes Delivered

### signal_bus.py

**DbC fixes:**
- `__init__`: Added `if func_gen is None: raise ValueError(...)`, `if toolkit is None: raise ValueError(...)`, `if poly_gen is None: raise ValueError(...)`
- `_on_func_gen_signal`: Replaced `assert signal is not None` with `if signal is None: raise ValueError("signal must not be None")`
- `_on_poly_generated`: Replaced `assert joint_name is not None` with `ValueError`; added `if not isinstance(coeffs, list): raise TypeError(...)`
- `_status`: Replaced `assert message is not None` with `if message is None: raise ValueError("message must not be None")`

### main_window.py

**LoD fix (module-level helper added before class):**
```python
def _connect_action(action: QAction, slot: object) -> None:
    if action is None: raise ValueError(...)
    if slot is None: raise ValueError(...)
    action.triggered.connect(slot)
```
- Lines 111, 117, 125: `action.triggered.connect(slot)` → `_connect_action(action, slot)`

**DbC fix:**
- `_on_poly_fallback`: Replaced `assert joint_name is not None` with `raise ValueError`; added `if not isinstance(coeffs, list): raise TypeError`

### __init__.py
