## Technical Notes

`defusedxml.ElementTree.ParseError` is a re-export of `xml.etree.ElementTree.ParseError`
(they are the same class). Using `DefusedET.ParseError` at catch-sites is both correct
and ensures the catch-site is explicitly anchored to the defusedxml import. The security
behavior is identical — defusedxml raises `EntitiesForbidden` (subclass of `ValueError`)
for XXE/DTD attacks, not ParseError — but using `DefusedET.ParseError` for malformed
XML errors makes the import dependency graph cleaner.
