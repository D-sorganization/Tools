# GH1704 Implementation Report

## Summary

Three files changed to address DbC enforcement inconsistency:

1. **`src/shared/python/contracts.py`** — Fixed stale-alias issue in `_handle_violation`, `require`, `ensure`, and `invariant` by replacing `DBC_LEVEL` module-alias reads with direct `_ContractState.level` reads. This makes enforcement level changes via `set_contract_level()` take effect immediately in all code paths without relying on `sys.modules` patching.

2. **`src/shared/python/upstream_drift_tools/process_calculators/scrubber_calculator.py`** — Added `require()` preconditions to 8 public functions that accept physical values (`temperature_k`, `pressure_pa`, `molecular_weight`, `gas_density`, `liquid_density`, etc.). Added one `ensure()` postcondition to `calculate_gas_density` asserting the result is positive. Replaced ad-hoc `assert foo is not None` guards with proper `require()` calls. Imported `require`, `ensure`, `check_temperature`, `check_pressure`, `check_positive`, `check_non_negative` from `contracts`.

3. **`tests/shared/python/process_calculators/test_scrubber_calculator.py`** — Added `TestScrubberCalculatorContracts` class with 17 new tests covering: zero/negative temperature/pressure/molecular_weight for gas_density, zero temperature/MW for gas_viscosity, invalid densities for flooding_velocity, invalid gas flow and percent-of-flood for column_diameter, invalid flow and condensate for heat_transfer_duty, and the contracts-OFF bypass behavior.
