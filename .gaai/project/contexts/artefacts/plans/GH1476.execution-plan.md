# GH1476 Execution Plan: Address TDD, DRY, DbC, and LOD in src/ode_solver

## Summary

Fix DbC and LoD violations in `src/ode_solver/python/ode_solver/ui/pyqt6/main_window.py`:

1. **DbC violations** in `_on_preset_changed` and `_parse_dict_input`: both currently use `assert` for input validation. The GAAI DbC convention requires `raise TypeError` for wrong types and `raise ValueError` for out-of-range — not `assert`, which is disabled in optimized mode (`python -O`).
2. **LoD violations** at lines 244, 249, 265 (in original numbering): deep attribute access chains accessing enum values via multi-level attribute chains (`Qt.ScrollBarPolicy.ScrollBarAlwaysOff`, `Qt.AlignmentFlag.AlignCenter`, `Qt.AlignmentFlag.AlignHCenter` etc.).
3. **Tests** must be added for the fixed functions.

## Approach Rationale

Approach follows established DbC convention in this codebase (raise TypeError/ValueError, document preconditions in docstring). LoD fix uses local variable aliasing to break deep chains (common PyQt6 convention observed in other modules). No `approach-evaluation` needed — established patterns apply.

## Implementation Steps

### Step 1: Fix DbC in `_on_preset_changed`

Replace `assert preset_name is not None` with proper `TypeError`/`ValueError` guard and add docstring precondition.

```python
def _on_preset_changed(self, preset_name: str) -> None:
    """Handle preset selection change.

    Preconditions:
        preset_name must be a non-empty string.

    Raises:
        TypeError: if preset_name is not a str.
        ValueError: if preset_name is an empty string.
    """
    if not isinstance(preset_name, str):
        raise TypeError(f"preset_name must be str, got {type(preset_name).__name__}")
    if not preset_name:
        raise ValueError("preset_name must not be empty")
    ...
```

### Step 2: Fix DbC in `_parse_dict_input`

Replace `assert text is not None` with proper guard and docstring precondition.

```python
def _parse_dict_input(self, text: str) -> dict[str, str]:
    """Parse colon-separated key-value pairs from text.

    Preconditions:
        text must be a str.

    Raises:
        TypeError: if text is not a str.
    """
    if not isinstance(text, str):
        raise TypeError(f"text must be str, got {type(text).__name__}")
```

### Step 3: Fix LoD violations

The three violations use deep Qt enum attribute access. Extract local aliases at the top of `_setup_ui` or at the call site.

- Line 244 (original): `Qt.ScrollBarPolicy.ScrollBarAlwaysOff` → alias to local variable
- Line 249 (original): `Qt.AlignmentFlag.AlignCenter` → alias to local variable
- Line 265 (original): deep attribute chain → alias

Preferred pattern (assign at call site or as module-level constants):
```python
# At module level (preferred for reuse):
_SCROLL_OFF = Qt.ScrollBarPolicy.ScrollBarAlwaysOff
_ALIGN_CENTER = Qt.AlignmentFlag.AlignCenter
```

Then use `_SCROLL_OFF` and `_ALIGN_CENTER` at call sites.
