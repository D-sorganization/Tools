# GH1648 Execution Plan

## Story
BLOCKER: Fix relative import regression in src/shared/python/cors.py

## Tier Assessment
Tier 1 — MicroDelivery. Complexity: 1. Files affected: 1. Criteria count: 5.

## Root Cause
`cors.py` line 23 uses `from .contracts import require` (relative import).
`src/shared/python/` is placed directly on `sys.path`, so `cors` is imported as
a top-level module with no package context. Relative imports require package
context — hence the import error breaking 30+ test files.

## Fix
Change line 23 from:
```python
from .contracts import require
```
to:
```python
from contracts import require
```

Ruff import-sort ordering also applied (contracts before fastapi — alphabetical).

## Files Affected
- `src/shared/python/cors.py` — 1 line change (relative → absolute import)
