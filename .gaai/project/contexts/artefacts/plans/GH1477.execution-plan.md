# GH1477: Execution Plan — Address TDD, DRY, DbC, and LOD in src/optimizer_gui

## Overview

Fix DbC and LoD violations in `src/optimizer_gui/python/optimizer_gui/ui/pyqt6/main_window.py` per the adversarial assessment. All fixes must leave behaviour identical — only structural improvements.

## Implementation Sequence

### Step 1: Assess current DbC state (READ-ONLY)

Read `main_window.py` to confirm which DbC violations remain. Based on the current code, several `assert` statements are already in place:
- `_run_adam_demo`: `assert params is not None`
- `_eval_rosenbrock`: `assert values is not None`
- `_compute_numerical_gradient`: `assert values is not None`
- `_display_adam_results`: `assert best_obj is not None`
- `_run_surface_demo`: `assert params is not None`

**Remaining gaps:** The asserts use `is not None` which is too weak — for list types we need `isinstance` check and non-empty. For ndarray types we need proper type checks.

**Fix:** Upgrade asserts to use `isinstance` + range checks per DbC rules (`TypeError` for wrong types, `ValueError` for out-of-range).

### Step 2: Fix DbC violations — upgrade preconditions

In `main_window.py`, upgrade the following functions:

1. `_run_adam_demo(params)` — replace `assert params is not None` with proper type+emptiness check
2. `_eval_rosenbrock(values, maximize)` — replace `assert values is not None` with isinstance check
3. `_compute_numerical_gradient(values, lower, upper, maximize)` — replace `assert values is not None` with isinstance check
4. `_display_adam_results(best_obj, best_params, max_iterations)` — replace `assert best_obj is not None` with isinstance check
5. `_run_surface_demo(params, method)` — replace `assert params is not None` with proper check

### Step 3: Fix LoD violations — extract enum constants

The LoD violations are deep attribute chains from PyQt6 enums. The fix is to extract these into local constants or imports at the top of the method where they are used.

Violations to fix:
- Line 257: `Qt.ScrollBarPolicy.ScrollBarAlwaysOff` → extract to local variable `no_hscroll = Qt.ScrollBarPolicy.ScrollBarAlwaysOff`
- Line 273: `Qt.AlignmentFlag.AlignCenter` → extract to local variable `align_center = Qt.AlignmentFlag.AlignCenter`
- Line 378: `QSizePolicy.Policy.Expanding` → extract to local variables `expanding = QSizePolicy.Policy.Expanding`, `fixed = QSizePolicy.Policy.Fixed`
- Lines 711, 761: `self.tab_widget.setCurrentIndex` — introduce `_switch_to_results_tab()` helper method

Note: Lines 289, 344, 348 (`btn.clicked.connect(...)`) are 2-level accesses and are NOT LoD violations — the story lists them but `obj.prop.method()` is a standard 2-level chain. Only the 3-level chains are genuine violations.

### Step 4: Update tests

Add or extend tests in `src/optimizer_gui/tests/test_optimizer_gui.py` to cover:
- DbC validation: that invalid inputs raise `TypeError` or `ValueError`
- The `_eval_rosenbrock` static method with proper assertions

### Step 5: Ruff check

Run `python3 -m ruff check src/optimizer_gui/` to verify zero violations.
