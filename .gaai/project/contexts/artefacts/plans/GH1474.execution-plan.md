# GH1474: Execution Plan — Address LoD Violations in src/media_processing

## Summary

Fix 4 Law of Demeter (LoD) violations across 2 files in `src/media_processing`. The pattern in all cases is `obj.prop.subprop` (chained attribute access). The fix is to introduce a local variable to hold the intermediate result.

## Violations to Fix

### File 1: `src/media_processing/video_processor/python/video_processor_src/api.py`

**Violation 1 — Line 191 (cancel_job endpoint)**
```python
detail=f"Cannot cancel job with status: {job.status.value}",
```
Fix: Extract `job.status` into a local variable before use.

**Violation 2 — Line 265 (start_processing endpoint)**
```python
detail=f"Job is not queued (current status: {job.status.value})",
```
Fix: Extract `job.status` into a local variable before the raise.

**Violation 3 — Line 270 (start_processing endpoint, return)**
```python
return {"success": True, "job_id": job_id, "status": job.status.value}
```
Fix: Extract `job.status` into a local variable before the return statement.

### File 2: `src/media_processing/video_processor/python/video_processor_src/logger_utils.py`

**Violation 4 — Line 57 (set_seeds fallback)**
```python
np.random.seed(seed)  # noqa: NPY002
```
Fix: Extract `np.random` into a local variable `np_random = np.random` before calling `.seed()`.

## Implementation Steps

### Step 1: Fix api.py violations

In `cancel_job` function (around line 185):
- After `job = _jobs[job_id]`, store `job_status = job.status`
- Use `job_status` in the `in (JobStatus.COMPLETED, JobStatus.FAILED)` check
- Use `job_status.value` (only 1 level deep from local var) in the detail string
- Use `job_status` when assigning `job.status = JobStatus.CANCELLED` (keep assignment direct)

In `start_processing` function (around line 251):
- After `job = _jobs[job_id]`, store `job_status = job.status`
- Use `job_status` in the `!= JobStatus.QUEUED` check
- Use `job_status.value` in the detail string
- After `job.status = JobStatus.PROCESSING`, re-read: `new_status = job.status`
- Use `new_status.value` in the return dict

### Step 2: Fix logger_utils.py violation

In the `set_seeds` fallback function:
- Add `np_random = np.random` before `np_random.seed(seed)` call

### Step 3: Write tests for the fixed behaviors

Add tests to `src/media_processing/video_processor/python/tests_video_processor/test_api.py` (new file):
- Test `cancel_job` returns correct status value in error messages
- Test `start_processing` returns correct status value in error messages
- Test `start_processing` returns the new status in success response

Note: Tests must use `pytest` with `httpx` + FastAPI `TestClient`.
