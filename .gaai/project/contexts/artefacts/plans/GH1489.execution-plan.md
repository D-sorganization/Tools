# GH1489 Execution Plan

## Story Summary

Address DbC and LoD violations in `Tools_Private/src/syngas_water_calculator/python/syngas_water_calculator/ui/pyqt6/main_window.py`.

## Tier

Tier 2 — Core Team (1 source file, 1 test file, 5 acceptance criteria)

## Violation Analysis

### DbC Violations

**`_display_water_content_results(self, result: Any)`** — no preconditions at all.
Fix: Add `if result is None: raise ValueError("result must not be None")`

**`_display_risk_assessment(self, risk: dict)`** — weak `assert risk is not None`.
Fix: Replace assert with `if not isinstance(risk, dict): raise TypeError(...)` + `if risk is None: raise ValueError(...)`

**`_display_calculation_error(self, error: Exception)`** — weak `assert error is not None`.
Fix: Replace assert with `if not isinstance(error, Exception): raise TypeError(...)`

### LoD Violations

All violations are 3-level enum attribute chains. Fix: module-level aliases.

| Line | Pattern | Alias |
|------|---------|-------|
| 186  | `Qt.ScrollBarPolicy.ScrollBarAlwaysOff` | `_SCROLL_ALWAYS_OFF` |
| 202  | `Qt.AlignmentFlag.AlignCenter` | `_ALIGN_CENTER` |
| 235  | `QSizePolicy.Policy.Expanding` | `_SIZE_EXPANDING` |
| 235  | `QSizePolicy.Policy.Fixed` | `_SIZE_FIXED` |
| 246  | `QSizePolicy.Policy.Expanding` | `_SIZE_EXPANDING` |
| 246  | `QSizePolicy.Policy.Fixed` | `_SIZE_FIXED` |

## Implementation Sequence

_ALIGN_CENTER = Qt.AlignmentFlag.AlignCenter
_SIZE_EXPANDING = QSizePolicy.Policy.Expanding

- Line 235: `QSizePolicy.Policy.Expanding` → `_SIZE_EXPANDING`, `QSizePolicy.Policy.Fixed` → `_SIZE_FIXED`
- Line 246: `QSizePolicy.Policy.Expanding` → `_SIZE_EXPANDING`, `QSizePolicy.Policy.Fixed` → `_SIZE_FIXED`

## Edge Cases

- Qt enum aliases defined at module level require PyQt6 available at import time. Tests mock PyQt6.
- `_display_risk_assessment` is called with dict from `estimate_condensation_risk` — `isinstance(risk, dict)` is appropriate.
- `_display_calculation_error` receives Exception from try/except — `isinstance(error, Exception)` is the correct check.
- `_display_water_content_results` receives a result dataclass — checking for None is sufficient; full type check would require importing the dataclass.
