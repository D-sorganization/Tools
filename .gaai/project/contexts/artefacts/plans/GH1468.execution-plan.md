### LoD Violations — Remaining

1. **`archive_ops.py` line 104** — `archive_path_obj.suffix.lower()`: Two-level chain.
   Fix: Extract `archive_ext = archive_path_obj.suffix` then apply `.lower()` separately.

2. **`archive_ops.py` line 43** — `os.path.splitext(archive_path)[0]`: indirect but acceptable.
   Use `archive_path_obj.stem` instead, which is cleaner and uses the already-existing Path obj.

3. **`archive_ops.py` line 142** — `Path(root) / file` inside os.walk loop: This constructs a path;
   acceptable pattern but could use local variable for clarity.

4. **`file_validation.py` line 47** — `Path(file_path).suffix.lower()`: Two-level chain.
   Fix: Extract suffix then lower.

5. **`file_validation.py` line 201** — `datetime.fromtimestamp(mtime).strftime("%Y/%m")`: Two-level chain.
   Fix: Assign intermediate datetime object.

6. **`Folders_Tool_r0.py` line 60** — `p.parent.mkdir(...)`: Two-level chain.
   Fix: Extract `parent_dir = p.parent` then call `parent_dir.mkdir(...)`.
