- `gas_composition`: must be a `dict`

## Edge Cases

- `calculate_flare_size` currently handles `total_flow=0` gracefully (returns design with
  heat_release=0, height=10). Preserve this behavior: `total_flow >= 0` is valid.
- `gas_composition` may contain keys not in `GAS_PROPERTIES`; the function silently ignores
  unknown gases. Preserve this behavior.
- GUI methods (`_create_input_panel`, `_create_results_panel`) are private; tests for those
  are not required (LoD fix is the priority).
- Tests that require PyQt6 widgets (non-headless) should be isolated; keep existing
  `TestFlareCalculatorMainWindow` tests as-is or guard with `headless_safe` marker.
