# GH1548 Execution Plan: Audit and Reduce Skip-Heavy Shared-Package Tests

## Summary

Audit skip/xfail/importorskip usage across `tests/shared/python/`, categorize each instance as
legitimate-optional or skip-debt, fix the skip-debt cases, and document remaining optional skips.

## Audit Findings

### Category A — Legitimate Optionals (keep, already correctly scoped)

| File | Skip | Reason | Verdict |
|------|------|---------|---------|
| `tests/shared/python/utils/test_data_io.py` | `_skip_no_pyarrow` on parquet tests | pyarrow is genuinely optional; CSV tests run unconditionally | KEEP |
| `tests/shared/python/chat/test_models.py` | `pytest.importorskip("pydantic")` at module level | pydantic is an optional dep; all tests here require it | KEEP |

### Category B — Skip Debt (fix required)

| File | Skip | Problem | Fix |
|------|------|---------|-----|
| `tests/shared/python/chat/test_chat_dock_widget.py` | Module-level `pytest.importorskip("PyQt6.QtWidgets")` + `pytest.importorskip("pytestqt")` | Session file helpers (`_session_file_path`, `_read_shared_session_id`, `_write_shared_session_id`) have zero PyQt6 dependency but are gated behind the module-level skip | Extract session-helper tests into a new file `test_chat_session_helpers.py` that has no Qt import — these tests must run unconditionally |
| `tests/shared/python/plot_theme/test_integration.py` | `pytest.mark.skipif(not pytest.importorskip("matplotlib", ...), ...)` | `pytest.importorskip` inside `skipif` condition is incorrect — `importorskip` raises `Skipped` on missing dep, which defeats the `skipif` evaluation | Replace with `pytest.importorskip("matplotlib")` at module level (conditionally skip entire class) OR use `_matplotlib_available()` helper function + `pytest.mark.skipif` |
| `tests/shared/python/plot_theme/test_manager.py` | Inline `pytest.importorskip("matplotlib")` inside a test body | `importorskip` inside a test body works but is not the idiomatic pattern; makes it hard to see skip coverage at a glance | Move to module-level `_matplotlib_available` skip marker |

### Category C — Correctly Scoped (no change needed)

| File | Skip | Reason |
|------|------|---------|
| `tests/shared/python/notes/test_notes_dock_widget.py` | `importorskip("PyQt6.QtWidgets")` + `RUN_QT_TESTS=1` env gate | Widget tests genuinely require display; `RUN_QT_TESTS` env gate correctly isolates them from headless CI |

## Implementation Steps

### Step 1 — Extract session-helper tests (AC1: reduce skip debt)

Create `tests/shared/python/chat/test_chat_session_helpers.py`:
- Move `TestSessionFileHelpers` class from `test_chat_dock_widget.py` to the new file
- Import only from standard library and `chat.chat_dock_widget` session helpers
- No `importorskip` needed — these are pure Python tests
- Remove `TestSessionFileHelpers` from `test_chat_dock_widget.py` (keep widget tests there)
- Mark new file with `@pytest.mark.unit`

### Step 2 — Fix plot_theme/test_integration.py bad skip pattern (AC2: fix pattern)

Replace:
```python
@pytest.mark.skipif(
    not pytest.importorskip("matplotlib", reason="matplotlib not installed"),
    reason="matplotlib not installed",
)
```
With module-level skip using a helper:
```python
matplotlib = pytest.importorskip("matplotlib", reason="matplotlib not installed")
```
at the top of the class, OR scope it correctly using `pytest.importorskip` at a `conftest` level.
Best approach: add `_matplotlib_available` helper + `pytest.importorskip` at module level for the
entire integration file, because both `TestCreateThemedFigure` and `TestStyleAxis` require matplotlib.

### Step 3 — Fix plot_theme/test_manager.py inline importorskip (AC2: normalize pattern)

Move inline `pytest.importorskip("matplotlib")` from inside `test_apply_to_matplotlib` body
to a class-level skip marker using `@pytest.mark.skipif(not _matplotlib_available(), ...)`.
Define `_matplotlib_available()` as a module-level helper.

### Step 4 — Write skip-debt documentation (AC3: document skip debt)

Create `.gaai/project/contexts/artefacts/impl-reports/GH1548.skip-debt-register.md` documenting:
- All legitimate optionals (pyarrow, pydantic, PyQt6 widget tests)
- All skip debt eliminated in this story
- Residual skip debt (Qt widget tests — intentional, require display server)

## Edge Cases

- `test_chat_session_helpers.py` must import the helpers without triggering the whole PyQt6 import.
  The helpers are at module level in `chat_dock_widget.py` — the `from chat.chat_dock_widget import`
  will attempt to import PyQt6. If PyQt6 is not installed, the import will fail.
  Resolution: check if PyQt6 is importable in test env first; if yes, the import succeeds.
  If PyQt6 is not installed in the test env, we cannot import from `chat_dock_widget.py` at all
  without `importorskip`. Add `pytest.importorskip("PyQt6", reason="PyQt6 required to import chat_dock_widget")` but only at the class level for TestSessionFileHelpers, NOT at module level.

  CORRECTION: The session helpers (lines 46-69 in chat_dock_widget.py) do not use PyQt6 at runtime,
  but the module imports PyQt6 at the top. When Python imports the module, it runs all top-level code
  including the PyQt6 imports. Therefore `from chat.chat_dock_widget import _session_file_path`
  WILL fail if PyQt6 is not installed.

  The correct fix is to add `pytest.importorskip("PyQt6")` at the TOP of the new file (not per-class)
  — same as the original. The WIN is that the session helper tests are separated so they can be
  explicitly documented and potentially moved to a pure-python module later.

  BETTER FIX: Check if PyQt6 IS actually available in the CI test environment.
