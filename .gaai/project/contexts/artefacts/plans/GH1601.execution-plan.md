## Implementation Steps

### Step 1: Fix `__init__.py` — Remove 6 `no-redef` ignores (highest value)

**Approach**: Declare fallback variables as `None` before the try/except with proper
Union type annotation. This eliminates the `no-redef` issue — the variable is now
declared once with the correct type.

Pattern (applies to SyngasWaterCalculator, WaterVaporPressureCalculator,
WGSReactorCalculator, WGSReactorEngine, PressureDropCalculator):

```python
# Before (requires type: ignore[no-redef])
try:
    from .syngas_water_calculator import SyngasWaterCalculator
except ImportError:
    SyngasWaterCalculator: type[SyngasWaterCalculatorType] | None = None  # type: ignore[no-redef]

# After (no type: ignore needed)
SyngasWaterCalculator: type[SyngasWaterCalculatorType] | None = None
try:
    from .syngas_water_calculator import SyngasWaterCalculator as SyngasWaterCalculator
except ImportError:
    pass
```

Note: Using `import X as X` is the standard pattern to re-export in TYPE_CHECKING-safe
way and avoids no-redef.

### Step 2: Fix `__init__.py` — Optimizer/AdamOptimizer/MultiParameterAnalysis/SyngasCompressionCalculator

These are function aliases, not class aliases, so the type is `Callable | None`.
Use the same pre-declare pattern:

```python
Optimizer: Callable[..., Any] | None = None
try:
    from .optimization import find_optimal_on_surface
    Optimizer = find_optimal_on_surface
except ImportError:
    pass
```

This removes the `assignment` and `misc, assignment` ignores.

### Step 3: Add mypy.ini section for psa_gui matplotlib attrs

The `plot_surface` and `set_zlabel` attr-defined errors come from matplotlib 3D Axes
not having stub definitions in CI. This is already handled for pendulum_simulator via
`warn_unused_ignores = False`. Add matching section:

```ini
[mypy-upstream_drift_tools.process_calculators.psa_package.psa_gui]
warn_unused_ignores = False
```

This allows the existing `type: ignore[attr-defined]` comments to stay without mypy
reporting them as "unused ignore" in local envs that have stubs.

**Alternative**: Remove the attr-defined ignores and add to mypy.ini with
`ignore_errors = True` for the psa_gui module. But this is heavier than needed.

The better approach is to cast the ax object to `Any`:
```python
import typing
ax: Any = self.canvas.fig.add_subplot(111, projection="3d")
surf = ax.plot_surface(...)
ax.set_zlabel(...)
```
This eliminates the need for type: ignore entirely.

### Step 4: Fix BaseCalculatorWidget fallback class in process_calculators

The `class BaseCalculatorWidget(QWidget): # type: ignore` pattern appears in 3 files:
- `syngas_compression_calculator.py` line 145
- `wgs_reactor_calculator.py` line 210
- `acid_gas_dewpoint_calculator.py` line 92

These are in a try/except ImportError block where QWidget is `object` in the fallback.
Since the class body correctly calls `QWidget.__init__`, the only issue is inheritance
from a dynamic base.

**Fix**: Use `cast` or annotate the class properly with `# type: ignore[misc]` being
more specific than bare `# type: ignore`. The bare ignores can be replaced with
specific codes. However, looking at the mypy issue: when QWidget=object, inheriting
from it is fine — the `# type: ignore` is needed because mypy doesn't know QWidget
is `object` at that point. Making these more specific `[misc]` reduces ambiguity but
doesn't remove the ignore.

**Best fix**: These three ignores should stay but be made more specific (add error code).
This doesn't reduce count but improves quality.

- Remove 1 `misc, assignment` from `__init__.py` via pre-declare pattern ✓
