# GH1696 Execution Plan: Resolve Large __init__.py God Modules

## Story Summary

Refactor large `__init__.py` files to reduce tight coupling by:
1. Extracting actual logic from `pressure_drop_calculator/__init__.py` into a dedicated module
2. Converting `signal_toolkit/__init__.py` to lazy imports

## Pre-Implementation Analysis

### Files Already Fixed
- `data_processor/core/__init__.py` (611 lines) — already uses `__getattr__` lazy imports (issue #530)
- `model_generation/__init__.py` (349 lines) — already uses `__getattr__` lazy imports (issue #611)
- `process_calculators/__init__.py` (187 lines) — already uses `TYPE_CHECKING` + try/except optional patterns

### Files Requiring Action (Priority Order)

| File | Lines | Issue | Action |
|------|-------|-------|--------|
| `pressure_drop_calculator/__init__.py` | 304 | Contains actual calculation logic (legacy `PressureDropCalculator` class, `PressureDropResult`, constants) | Extract to `_legacy.py` |
| `signal_toolkit/__init__.py` | 239 | Eager eager imports of 8 submodules | Convert to `__getattr__` lazy imports |
| `rotation_converter/__init__.py` | 208 | Deprecated module, eager imports | Convert to `__getattr__` lazy imports |
| `programmatic_pid/__init__.py` | 119 | Eager imports | Convert to `__getattr__` lazy imports |
| `humanoid_character_builder/__init__.py` | 115 | Eager imports | Convert to `__getattr__` lazy imports |

**Scope decision**: Focus on the two highest-impact changes per story recommendation:
1. `pressure_drop_calculator/__init__.py` — extract legacy logic (explicit recommendation in issue)
2. `signal_toolkit/__init__.py` — lazy imports (largest pure re-export case)

The deprecated `rotation_converter/__init__.py` conversion is low-priority (deprecated module). The `programmatic_pid` and `humanoid_character_builder` files are below 120 lines and lower risk.

## Implementation Sequence

### Step 1: Extract legacy code from `pressure_drop_calculator/__init__.py`

**File**: `src/shared/python/upstream_drift_tools/process_calculators/pressure_drop_calculator/_legacy.py` (NEW)

Move lines 162-304 (the `PIPE_DIMENSIONS_SCH40`, `ROUGHNESS_VALUES`, `PressureDropResult`, `PressureDropCalculator`) to `_legacy.py`.

Update `__init__.py` to import from `_legacy.py` instead of defining inline.

**Result**: `__init__.py` drops from 304 → ~115 lines.

**Public API remains identical** — all exports unchanged.

### Step 2: Convert `signal_toolkit/__init__.py` to lazy imports

Replace all static `from .submodule import X, Y, Z` with a `__getattr__` dispatch table.

Pattern:
```python
_LAZY_IMPORTS: dict[str, tuple[str, str]] = {
    "Signal": (".core", "Signal"),
    "SignalGenerator": (".core", "SignalGenerator"),
    # ... etc
}

def __getattr__(name: str) -> Any:
    if name in _LAZY_IMPORTS:
        module_path, attr = _LAZY_IMPORTS[name]
        import importlib
        mod = importlib.import_module(module_path, package=__name__)
        return getattr(mod, attr)
    raise AttributeError(f"module {__name__!r} has no attribute {name!r}")
```

Keep optional imports (`PolynomialGeneratorWidget`, `SignalToolkitWidget`) with try/except at module load since they already handle ImportError gracefully.

**Result**: `__init__.py` drops from 239 → ~80 lines. Import time reduced significantly.

**Public API (`__all__`) remains identical.**

### Step 3: Write tests

**New test file**: `tests/architecture/test_gh1696_god_modules.py`

Tests:
1. `test_pressure_drop_legacy_api_preserved` — verify all legacy symbols importable from `pressure_drop_calculator`
2. `test_pressure_drop_calculator_legacy_compute` — verify `PressureDropCalculator.calculate_pressure_drop()` produces correct results
3. `test_signal_toolkit_lazy_imports` — verify all `__all__` symbols accessible via lazy import
4. `test_signal_toolkit_import_defers_submodules` — verify submodules not loaded at package import time (check `sys.modules`)
5. `test_init_line_count_pressure_drop` — regression guard: `__init__.py` must be < 160 lines
6. `test_init_line_count_signal_toolkit` — regression guard: `__init__.py` must be < 120 lines
7. `test_legacy_constants_correct` — verify `PIPE_DIMENSIONS_SCH40` and `ROUGHNESS_VALUES` values

## Edge Cases

- `__all__` must remain identical for both files (downstream consumers use `from pkg import *`)
- Lazy imports must support attribute access AND `from signal_toolkit import X` (both work via `__getattr__`)
- The `logger` in `signal_toolkit/__init__.py` must remain module-level (not lazy)
- Optional widgets (`PolynomialGeneratorWidget`, `SignalToolkitWidget`) use try/except — keep this pattern
- `PressureDropCalculator` in `__init__.py` is also exported via `process_calculators/__init__.py` (line 148) — verify import chain still works

## Risk Register

| Risk | Severity | Mitigation |
|------|----------|------------|
| Downstream breakage from `signal_toolkit` lazy import | Medium | Keep `__all__` identical; lazy `__getattr__` is Python-standard |
| `PressureDropCalculator` import path changes | Low | Re-export from `__init__.py` unchanged |
| Optional widget try/except in lazy context | Low | Keep optional imports at module-level (not lazy) |
| Test coverage regression on touched files | Low | New tests specifically target the changed code |

## Rollback Boundaries

- Each file is independently modifiable
- Step 1 (pressure_drop) and Step 2 (signal_toolkit) are independent
- If lazy import causes issues in `signal_toolkit`, revert only that file
