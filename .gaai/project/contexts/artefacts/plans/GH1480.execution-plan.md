# GH1480 Execution Plan

## Story Summary

Address DbC and LoD violations in `src/pressure_drop_calculator`:
- `src/pressure_drop_calculator/python/pressure_drop_calculator/ui/pyqt6/main_window.py`

## Tier

Tier 1 — MicroDelivery (1 source file, 4 violations: 1 DbC + 3 LoD)

## Violation Analysis

### main_window.py

**DbC Violation:**
- `PressureDropCalculatorWidget.__init__`: `parent: QWidget | None = None` argument has no type check. Must validate that `parent` is either `None` or a `QWidget` instance.

**LoD Violations:**
- Line 12: `os.environ.get("HEADLESS", "false").lower() == "true"` — 3-level chain (`os.environ.get(...)` returns a str, then `.lower()` is called on it). Fix: extract intermediate result.
- Line 104: `Qt.Orientation.Horizontal` — 3-level chain through namespace hierarchy. Fix: extract to module-level or local constant.
- Line 426: `ax.spines.values()` — accessed inside `for spine in ax.spines.values()`. Fix: extract `spines = ax.spines` before iteration.

## Implementation Sequence

### Step 1: Fix LoD at line 12 (module-level condition)

Before:
```python
if os.environ.get("HEADLESS", "false").lower() == "true":
```

After:
```python
_headless_env = os.environ.get("HEADLESS", "false")
if _headless_env.lower() == "true":
```

### Step 2: Fix LoD at line 104 (Qt orientation chain)

In `_init_ui`:
```python
orientation = Qt.Orientation.Horizontal
splitter = QSplitter(orientation)
```

### Step 3: Fix LoD at line 426 (spines iteration)

In `_update_chart`:
```python
spines = ax.spines
for spine in spines.values():
    spine.set_color("#585b70")
```

### Step 4: Fix DbC in __init__

Add type precondition at start of `__init__`:
```python
if parent is not None and not isinstance(parent, QWidget):
    raise TypeError(f"parent must be a QWidget or None, got {type(parent).__name__}")
```

### Step 5: Write tests

Add tests in `src/pressure_drop_calculator/tests/test_pressure_drop_calculator_gui.py`:
- Test DbC: `__init__` raises `TypeError` on invalid parent type
- Test that `HEADLESS` env extraction does not break behavior (mock os.environ)

### Step 6: Verify ruff

Run `ruff check` and `ruff format --check` on modified files.
