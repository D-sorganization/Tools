# GH1656 Execution Plan: Add ODE Solver Timeout and Load Testing

## Summary

The ODE solver currently runs solve operations unconstrained — a stiff or pathological ODE system
can hang indefinitely. This story adds:

1. **Timeout decorator** (`with_timeout`) in a new `src/ode_solver/python/ode_solver/timeout.py`
   module, implemented with `threading.Timer` (cross-platform, no `signal.SIGALRM` dependency).
   The decorator wraps callable computation, raising `TimeoutError` if the deadline is exceeded.

2. **Timeout integration** in `main_window.py` `_solve()` — the solver call is wrapped with
   `with_timeout`, displaying a user-friendly error when the timeout fires.

3. **Load/performance tests** in a new `tests/ode_solver/test_ode_solver_timeout.py`, using
   `time.perf_counter()` timing (consistent with `test_syngas_water_overflow.py` pattern) and
   marked `@pytest.mark.slow` + `@pytest.mark.performance`.

## Approach Rationale

- `threading.Timer`-based timeout: portable (works on Windows/Linux/macOS unlike `signal.SIGALRM`)
  and compatible with pytest's parallel execution (`-n auto`).
- DbC applied to `with_timeout` public interface: `TypeError` for wrong types, `ValueError` for
  out-of-range seconds.
- No new pytest-benchmark marker added — existing `performance` + `slow` markers cover load tests
  per current conventions.
- Timeout module placed inside the `ode_solver` package, not in `src/shared/`, to keep dependency
  boundary clear (Tools coding standards: modules must not import across package boundaries).

## Implementation Steps

### Step 1: Create `timeout.py`

```python
# src/ode_solver/python/ode_solver/timeout.py
"""Timeout decorator for ODE solver computations."""
import logging
import threading
from collections.abc import Callable
from typing import Any, TypeVar

_T = TypeVar("_T")
_log = logging.getLogger(__name__)

class SolverTimeoutError(TimeoutError):
    """Raised when a solver computation exceeds its time budget."""

def with_timeout(seconds: float, func: Callable[..., _T], *args: Any, **kwargs: Any) -> _T:
    """Run func(*args, **kwargs), raising SolverTimeoutError if it exceeds `seconds`."""
    # DbC guards
    if not isinstance(seconds, (int, float)):
        raise TypeError(f"seconds must be numeric, got {type(seconds).__name__}")
    if seconds <= 0:
        raise ValueError(f"seconds must be > 0, got {seconds}")
    if not callable(func):
        raise TypeError(f"func must be callable, got {type(func).__name__}")

    result: list[Any] = []
    exc: list[BaseException] = []

    def target() -> None:
        try:
            result.append(func(*args, **kwargs))
        except Exception as e:  # noqa: BLE001
            exc.append(e)

    thread = threading.Thread(target=target, daemon=True)
    thread.start()
    thread.join(timeout=seconds)
    if thread.is_alive():
        _log.warning("ODE solver timed out after %.1fs", seconds)
        raise SolverTimeoutError(f"Solver timed out after {seconds}s")
    if exc:
        raise exc[0]
    return result[0]
```

### Step 2: Modify `main_window.py` `_solve()`

### Step 3: Create `tests/ode_solver/test_ode_solver_timeout.py`
