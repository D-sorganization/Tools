# GH1735 Execution Plan — DRY Violations in pendulum_simulator

## Summary

Extract shared helpers and fixtures to eliminate repeated code blocks identified
as DRY violations across:
- `src/pendulum_simulator/tests/test_club_forces.py`
- `src/pendulum_simulator/tests/test_analytical_jacobians.py`
- `src/pendulum_simulator/src/double_pendulum_golf/gui/analysis_tab.py`

## Implementation Sequence

### Step 1 — Fix `test_club_forces.py`: Extract repeated setup into fixture

**Violation:** In `TestClubForceDecomposition`, three test methods each inline:
```python
from double_pendulum_golf.club_forces import club_force_decomposition
from double_pendulum_golf.golfer_constraints import net_joint_forces
q = np.zeros(8)
qdot = np.zeros(8)
qddot = np.zeros(8)
forces = net_joint_forces(q, qdot, qddot, default_params)
```

**Fix:** Add a `decomposition_result` fixture to `TestClubForceDecomposition` that
computes `q`, `qdot`, `qddot`, `forces`, and `result` once. Each test method uses
the fixture instead of repeating the setup.

**File:** `src/pendulum_simulator/tests/test_club_forces.py`

### Step 2 — Fix `test_analytical_jacobians.py`: Extract assertion helper

**Violation:** In `TestJacobianHelpers`, three test methods each inline:
```python
for key in (...):
    np.testing.assert_allclose(
        np.array(helpers[key]),
        np.array(full[key]),
        atol=1e-10,
        err_msg=f"Mismatch in key '{key}'",
    )
```

**Fix:** Extract a module-level helper function `_assert_jac_keys_match(helpers, full, keys)`
that encapsulates the loop and assertion. Call it from each test.

**File:** `src/pendulum_simulator/tests/test_analytical_jacobians.py`

### Step 3 — Fix `analysis_tab.py`: Extract repeated evaluator sub-pattern

**Violation:** In `_evaluator_double`, `_evaluator_triple`, `_evaluator_golfer`,
the `mass_matrix_det` and `mass_matrix_cond` evaluator closures follow the same
pattern: get matrix M via a model-specific call, then `np.linalg.det(M)` or
`np.linalg.cond(M)`.

**Fix:** Add two module-level factory functions:
- `_make_det_evaluator(matrix_fn)` → returns closure that calls `matrix_fn` then computes det
- `_make_cond_evaluator(matrix_fn)` → returns closure that calls `matrix_fn` then computes cond

Each model-specific evaluator calls these factories instead of inlining the closures.

**File:** `src/pendulum_simulator/src/double_pendulum_golf/gui/analysis_tab.py`

## Edge Cases

- AC2 (TDD): All extracted helpers must have corresponding tests verifying the
  extracted behavior. For fixture-based refactors, tests that pass after refactoring
  serve as validation. For `analysis_tab.py` factory functions, existing tests cover
  indirectly; add a direct unit test in test_analysis_tab.py.

- The `GolferParams` duplication across test files is intentional (each test file uses
  different parameter values — `_PARAMS` in test_analytical_jacobians vs `params` fixture
  in test_club_forces_extended have different mass values). Do NOT consolidate them.

## Test Checkpoints

1. After each file change: `python3 -m ruff check src/pendulum_simulator/`
2. After all changes: `python3 -m ruff format --check src/pendulum_simulator/`
3. Run relevant tests:
   - `python3 -m pytest src/pendulum_simulator/tests/test_club_forces.py -x`
   - `python3 -m pytest src/pendulum_simulator/tests/test_analytical_jacobians.py -x`
   - `python3 -m pytest src/pendulum_simulator/tests/test_analysis_tab.py -x`

## Risk Register

| Risk | Likelihood | Mitigation |
|------|-----------|------------|
| Fixture scope breaks test isolation | Low | Use method-level fixture scope |
| Factory functions change evaluator behavior | Low | Existing tests validate same output |
| Ruff format diffs on restructured code | Medium | Run ruff format before committing |

## Rollback Boundaries

Each step is independent. If Step 3 fails, Steps 1 and 2 can still be committed.
