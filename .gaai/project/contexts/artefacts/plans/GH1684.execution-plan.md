# Execution Plan: GH1684

## Story
Assessment: ruff.toml lacks T201 rule — print() calls bypass CI linting

## Approach

### Problem Summary
`ruff.toml` (the active config) selects rules `["E", "F", "W", "I", "B", "UP"]` but excludes `T201`.
This allows `print()` calls to bypass CI linting. Two confirmed violations exist in
`src/rotation_converter/modern_robotics.py` (lines 1464, 1583).

### Changes Required

**File 1: `ruff.toml`**
- Add `"T201"` to the `select` list in `[lint]` section
- Already has `per-file-ignores` for `scripts/**/*.py` and `scripts/*.py` — these can remain
- Need to add `**/*.ipynb` T201 exclusion since pyproject.toml has it and notebooks use print legitimately

**File 2: `src/rotation_converter/modern_robotics.py`**
- Add `import logging` at the top (after existing imports)
- Add `_logger = logging.getLogger(__name__)` module-level variable
- Replace `print('The result will not be plotted due to a lack of package matplotlib')` at line 1464
  with `_logger.warning('The result will not be plotted due to a lack of package matplotlib')`
- Replace same pattern at line 1583 with same logging call

### Test Strategy
Existing `tests/test_gh1655_print_to_logging.py` covers:
- `TestModernRoboticsLogging::test_module_has_logger` — verifies `_logger` attribute
- `TestModernRoboticsLogging::test_logger_name_is_module` — verifies logger name
- `TestModernRoboticsLogging::test_import_logging_present` — verifies `logging` imported
- `TestNoUnguardedPrintInSrc::test_no_bare_print_in_modern_robotics` — verifies no print() calls
- `TestRuffT201Configured::test_t201_in_ruff_select` — checks pyproject.toml (already has T201)
- `TestRuffT201Configured::test_notebooks_excluded_from_t201` — checks pyproject.toml (already OK)

All 6 tests should pass after the changes.

### AC Mapping
- AC1: Add T201 to ruff.toml → ruff check will detect print() calls
- AC2: Tests already exist (TDD met by test_gh1655_print_to_logging.py)
- AC3: ruff check passes on modified files
- AC4: No new print() calls in src/
- AC5: PR created targeting staging
