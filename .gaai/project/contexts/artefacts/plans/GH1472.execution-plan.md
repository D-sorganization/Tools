# Execution Plan: GH1472 — Address LoD Violations in src/humanoid_builder_gui

## Story Summary

Fix Law of Demeter (LoD) violations in `src/humanoid_builder_gui/python/humanoid_builder_gui/ui/pyqt6/main_window.py`. All violations are deep attribute access chains (3+ levels) on PyQt6 enum namespaces.

## Tier Assessment

**Tier 2** — single file change, well-scoped, 5 acceptance criteria, complexity ~3.

## Violation Analysis

All flagged violations resolve to accessing PyQt6 enum constants via their 3-level namespace paths:

| Line(s) | Violation | Resolution |
|---------|-----------|------------|
| 326 | `Qt.ScrollBarPolicy.ScrollBarAlwaysOff` | Import `ScrollBarPolicy` directly |
| 342 | `Qt.AlignmentFlag.AlignCenter` | Import `AlignmentFlag` directly |
| 359 | `build_btn.clicked.connect(self._build_character)` | Signal connect is a standard pattern, not a LoD violation — false positive |
| 384 | `QSizePolicy.Policy.Expanding`, `QSizePolicy.Policy.Fixed` | Import `SizePolicy` (alias for Policy) directly |
| 422, 435, 501 | `Qt.Orientation.Horizontal` | Import `Orientation` directly |
| 510 | `slider.valueChanged.connect(...)` | Signal connect on local var — standard pattern, not a LoD violation |
| 520 | `reset_btn.clicked.connect(...)` | Signal connect on local var — standard pattern, not a LoD violation |
| 566, 568 | `QHeaderView.ResizeMode.Stretch`, `QHeaderView.ResizeMode.ResizeToContents` | Import `ResizeMode` directly |
| 623, 628 | `preview_btn.clicked.connect(...)`, `export_btn.clicked.connect(...)` | Signal connect on local vars — standard pattern |

**Note:** PyQt6 signal `.connect()` calls are a single-level method call on the signal object; they are not LoD violations. The true violations are the 3-level enum namespace accesses.

## Implementation Steps

### Step 1: Update imports in `main_window.py`

Add enum-class imports to the `from PyQt6.QtCore import Qt` and `from PyQt6.QtWidgets import ...` blocks:

```python
from PyQt6.QtCore import Qt, Qt as QtNS
# Instead, import specific enum classes:
from PyQt6.QtCore import Qt
from PyQt6.QtCore import Qt  # already there; add:
from PyQt6.QtWidgets import QHeaderView  # already there
```

Specifically add to imports:
- `from PyQt6.QtCore import Qt` (keep existing)
- `from PyQt6.QtWidgets import QSizePolicy` (add)

And at module level after imports, create local aliases:
```python
ScrollBarAlwaysOff = Qt.ScrollBarPolicy.ScrollBarAlwaysOff
AlignCenter = Qt.AlignmentFlag.AlignCenter
Horizontal = Qt.Orientation.Horizontal
PolicyExpanding = QSizePolicy.Policy.Expanding
PolicyFixed = QSizePolicy.Policy.Fixed
ResizeModeStretch = QHeaderView.ResizeMode.Stretch
ResizeModeResizeToContents = QHeaderView.ResizeMode.ResizeToContents
```

### Step 2: Replace all occurrences in `main_window.py`

Replace deep access chains with the module-level aliases defined in Step 1.

### Step 3: Verify tests

Run existing tests in `src/humanoid_builder_gui/tests/test_humanoid_builder_gui.py`. They are mostly headless-safe (mock PyQt6 or pure calculation tests). Confirm they pass.

### Step 4: Add a new test

Add a test to `test_humanoid_builder_gui.py` that verifies the module-level enum aliases exist and have the correct types/values.

### Step 5: Ruff check

Run `python3 -m ruff check src/humanoid_builder_gui/` — must pass with 0 violations.

## Edge Cases

- PyQt6 enum aliases must be defined AFTER the imports (module-level constants).
- `QSizePolicy` may need to be added to the `from PyQt6.QtWidgets import ...` block.
- Signal `.connect()` calls are NOT LoD violations and should not be changed.
