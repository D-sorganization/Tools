# GH1494 Execution Plan

## Story Summary

Address LoD violations in `src/verification`. Three files each contain a 2-level attribute/method chain that violates the Law of Demeter (no method chains >2 levels).

## Pre-Analysis Findings

All three files are Playwright-based verification/smoke scripts. The violations are chained attribute access or method chains on Playwright objects. The fix pattern is: extract the intermediate object into a local variable, then call the method on the local.

No existing tests for `src/verification` modules. Tests directory `tests/verification/` does not exist.

## Violations to Fix

### LoD — `verify_a11y.py` line 12
`browser = p.chromium.launch(headless=True)`
- `p.chromium` accesses attribute `chromium` of `p`, then `.launch()` is called on it.
- Fix: `chromium = p.chromium` then `browser = chromium.launch(headless=True)`.

### LoD — `verify_palette.py` lines 44-46
`described_by = page.locator("#standardCondition").get_attribute("aria-describedby")`
- `page.locator(...)` returns a Locator; `.get_attribute(...)` is called on it — 2 chained calls.
- This is a 3-level chain: `page` → `.locator(...)` → `.get_attribute(...)`.
- Fix: `condition_locator = page.locator("#standardCondition")` then `described_by = condition_locator.get_attribute("aria-describedby")`.

Also line 31 in verify_palette_final.py (same pattern):
`hint_text = from_label.locator(".kbd-shortcut").inner_text()`
- Fix: `kbd_shortcut = from_label.locator(".kbd-shortcut")` then `hint_text = kbd_shortcut.inner_text()`.

### LoD — `verify_palette_final.py` lines 13 and 46-48
Line 13: `context = browser.new_context()` — only 2 levels (browser → method), acceptable.
Line 46-48: `described_by = page.locator("#standardCondition").get_attribute("aria-describedby")`
- Same pattern as verify_palette.py.
- Fix: extract locator to local variable.
Also line 31: `hint_text = from_label.locator(".kbd-shortcut").inner_text()`
- Fix: extract locator to local variable.

## Implementation Sequence

### Step 1: Fix `verify_a11y.py`
- Extract `chromium = p.chromium` before `browser = chromium.launch(headless=True)`

### Step 2: Fix `verify_palette.py`
- Extract `condition_locator = page.locator("#standardCondition")` before `.get_attribute()` call

### Step 3: Fix `verify_palette_final.py`
- Extract `kbd_shortcut = from_label.locator(".kbd-shortcut")` before `.inner_text()` call
- Extract `condition_locator = page.locator("#standardCondition")` before `.get_attribute()` call

### Step 4: Write tests
- Create `tests/verification/` directory with `__init__.py`
- Write `tests/verification/test_verification_lod.py` covering:
  - Unit tests for the public entry-point functions using mocks (no real browser)
  - Verify LoD fixes by ensuring each function is callable and that mock calls are correct
  - All tests marked `@pytest.mark.unit`

### Step 5: Quality gates
- `ruff check` on modified files
- `ruff format --check` on modified files
- Run new tests
