# GH1693 Execution Plan: Remove Dead Root-Level Duplicate Files in urdf_builder_gui

## Summary

Six `.py` files exist in both `src/urdf_builder_gui/` (root-level) and
`src/urdf_builder_gui/python/urdf_builder_gui/` (canonical package location).

The `python/` subdirectory is the canonical pip-installable package. The root-level
`__init__.py` injects `python/` into `sys.path`, making `import urdf_builder_gui`
resolve to `python/urdf_builder_gui/`. The root-level copies of the other 5 modules
(contracts.py, theme.py, anthropometric_model.py, urdf_generator.py,
preview_generator.py) are therefore dead code — no file imports them from their
root location.

The `TestFileSyncIntegrity` test was previously added to catch drift between the two
copies, but the correct fix is to eliminate the duplication by removing the dead
root-level copies entirely.

## Approach Evaluation

No non-obvious choices. The `python/` directory IS the packaging layout (evidenced by
`python/urdf_builder_gui/__init__.py` = "PyQt6 GUI for Parametric URDF Builder" and
the `ui/pyqt6/` subdirectory inside it). The top-level `__init__.py` explicitly
inserts `python/` into sys.path to point at the package. Root-level copies are
vestigial. No approach evaluation artefact needed.

## File-Level Steps

### Step 1: Remove 5 dead root-level module copies

**Files to delete from `src/urdf_builder_gui/`:**
- `contracts.py`
- `theme.py`
- `anthropometric_model.py`
- `urdf_generator.py`
- `preview_generator.py`

These are confirmed identical to their `python/urdf_builder_gui/` counterparts (diff=0).
They are never imported from the root location — all imports go via `urdf_builder_gui.*`
which resolves to `python/urdf_builder_gui/`.

### Step 2: Update `TestFileSyncIntegrity` to reflect the new layout

**File:** `src/urdf_builder_gui/tests/test_urdf_builder_gui.py`

The `TestFileSyncIntegrity` class currently verifies that root-level copies match
`python/` copies. After removal, replace this class with
`TestNoRootLevelDuplicates` which verifies that the root-level copies do NOT exist.
This guards against anyone accidentally re-introducing the duplication.

**New test class:**
```python
class TestNoRootLevelDuplicates:
    """Guard: root-level module copies must not exist after DRY cleanup (GH1693).

    The canonical location for urdf_builder_gui modules is
    src/urdf_builder_gui/python/urdf_builder_gui/.
    Root-level copies are dead code and must not be present.
    """

    _REMOVED_MODULES = [
        "contracts.py",
        "anthropometric_model.py",
        "urdf_generator.py",
        "preview_generator.py",
        "theme.py",
    ]

    def test_root_level_duplicates_do_not_exist(self) -> None:
        """Verify no root-level module copies exist (DRY enforcement)."""
        from pathlib import Path

        root_dir = Path(__file__).resolve().parent.parent
        present: list[str] = []
        for mod_name in self._REMOVED_MODULES:
            if (root_dir / mod_name).exists():
                present.append(mod_name)

        assert not present, (
            "Root-level module copies re-introduced (DRY violation, GH1693):\n"
            + "\n".join(f"  • {m}" for m in present)
        )
```

### Step 3: Verify ruff passes on modified file

Run `ruff check` on `src/urdf_builder_gui/tests/test_urdf_builder_gui.py` after editing.

## Edge Cases

- `src/urdf_builder_gui/__init__.py` stays unchanged — it sets up sys.path to point at
  `python/`, which is essential for the GUI launcher bootstrap. Do NOT delete or modify it.
- `src/urdf_builder_gui/conftest.py` stays unchanged — same purpose (sys.path for tests).
- `src/urdf_builder_gui/gui_registration.py` and `launch_pyqt6.py` are NOT duplicated —
  they only exist at the root level. Do not touch them.
- `src/urdf_builder_gui/python/urdf_builder_gui/` files are completely unchanged.
