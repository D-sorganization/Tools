## Violations Remaining (Post-Prior-Partial-Fix)

### run_app.py

The story flags 6 LoD violations at lines 14, 21, 24 — these are `os.path` chained calls:
- Line 14: `os.path.dirname(os.path.abspath(__file__))` — nested call
- Line 21: `os.path.join(os.path.dirname(__file__), "tests")` — chained path
- Line 24: `cwd=os.path.dirname(__file__)` — standalone (not a chain)

Fix: Extract path constants at module level to eliminate chaining.

### python/app.py

**DbC remaining violations:**
The following functions have arguments but lack adequate preconditions:
- `__init__` (AppState) — no arguments to validate
- `_set_and_recalc` — `state`, `attr`, `value`, `recalc` arguments, no assertion
- `_set_pressure` — `state`, `atm_value`, `recalc` arguments, no assertion
- `_set_oxidant` — no assertion
- `_set_air_mode` — no assertion
- `_set_injection` — no assertion
- `_set_feed_element` — no assertion
- `GasificationApp.__init__` — no assertion

**LoD remaining violations:**
- `btn.label.set_color(...)` and `btn.label.set_fontweight(...)` in `make_button` (lines 81-82)
  Fix: Extract a helper `_style_button_label(btn, color)` or use a single call pattern

## Implementation Sequence

### Step 1: Fix LoD violations in run_app.py

Extract `__file__` dirname to a module-level constant to eliminate chained `os.path` calls.

```python
_THIS_DIR = os.path.dirname(os.path.abspath(__file__))
```

Use `_THIS_DIR` consistently throughout.

### Step 2: Fix LoD violations in python/app.py

In `make_button`, the chain `btn.label.set_color(...)` and `btn.label.set_fontweight(...)` both
access `btn.label` twice. Introduce a local variable:

```python
lbl = btn.label
lbl.set_color(COLORS["bg"])
lbl.set_fontweight("bold")
```

### Step 3: Add DbC preconditions to private helpers in python/app.py

Add minimal, meaningful preconditions to the remaining private helper functions:
- `_set_and_recalc`: validate `state` is not None, `attr` is a non-empty string
- `_set_pressure`: validate `state` is not None, `atm_value > 0`
- `_set_oxidant`: validate `state` is not None, `o2_moles >= 0`
- `_set_air_mode`: validate `state` is not None, `label` is a non-empty string
- `_set_injection`: validate `state` is not None, `stream_name` non-empty, `flow >= 0`
- `_set_feed_element`: validate `state` is not None, `elem` non-empty, `value >= 0`
- `GasificationApp.__init__`: no meaningful preconditions needed (engine=None is valid)

### Step 4: Write tests for app.py (TDD — AC2)

Create `tests/test_app.py` with:
- Tests for `make_slider` (mock fig, validate preconditions)
- Tests for `make_button` (mock fig, validate preconditions)
- Tests for `build_single_point_tab` preconditions
- Tests for `build_sweep_tab` preconditions
- Tests for `build_surface_tab` preconditions
- Tests for `build_feed_tab` preconditions
- Tests for `_set_and_recalc` preconditions
- Tests for `_set_pressure` preconditions (and behaviour)
- Tests for `_set_oxidant` preconditions

- Tests for `_set_injection` preconditions
- Tests for `_set_feed_element` preconditions

### Step 5: Verify ruff passes on modified files

Run `python3 -m ruff check src/gasification_equilibrium/` in the worktree.
