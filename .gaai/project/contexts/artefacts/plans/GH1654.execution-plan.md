# GH1654 Execution Plan

## Story
Reduce blanket `# type: ignore` comments (currently 719) to under 200.
Strategy: replace blanket ignores with specific error codes or remove unused ignores.

## Current State (Measured)
- Total `# type: ignore$` (bare, no code): 719
- Total `# type: ignore[...]` (with codes): 575
- Unused bare ignores (mypy warns as [unused-ignore]): 255 (in 41 files)
- Bare ignores in excluded/unchecked files: ~464

## Approach

### Phase 1: Remove Provably Unused Bare Ignores (255 lines)
Files where mypy actively checks and reports `[unused-ignore]` — remove the `# type: ignore` comment from those lines. These suppress nothing and can be safely deleted.

Primary files:
- `src/folder_packer_pro/ui_tabs.py` (94 unused)
- `src/pendulum_simulator/...controls_widget.py` (16 unused)
- `src/pendulum_simulator/...controls_widget_golfer.py` (15 unused)
- `tests/rotation_converter/test_rotation_converter_advanced.py` (12 unused)
- `tests/tools/test_launch_utils.py` (11 unused)
- `tests/shared/python/data_processing/test_processor.py` (9 unused)
- `src/pendulum_simulator/...controls_widget_triple.py` (8 unused)
- `tests/tools/test_quality_utils.py` (7 unused)
- `src/pendulum_simulator/...analysis_tab.py` (6 unused)
- `tests/.../test_registry.py` (6 unused)
- `tests/ode_solver/test_main_window.py` (5 unused)
- `src/folder_packer_pro/dialogs.py` (5 unused)
- `tests/tools/test_matlab_quality_utils.py` (6 unused)
- 28 more files with 1-4 unused each

Method: Parse mypy output for [unused-ignore] lines. For each file:line, read line, strip `  # type: ignore` (with any trailing content if bare), leave the code.

### Phase 2: Add Specific Error Codes to Remaining Bare Ignores
For the ~464 bare ignores in excluded/unchecked modules, add `[attr-defined]` as the most common error code for tkinter/mixin attribute patterns. For numpy/GPU files use `[assignment]`. For return-type patterns use `[no-any-return]`.

Primary files to fix:
- `src/folder_tool/folder_ops.py` (49 bare) → mixin attrs → `[attr-defined]`
- `src/folder_tool/folder_tool_ui.py` (39 bare → 37 after removing 2 unused)
- `src/folder_tool/folder_tool_analysis.py` (25 bare → 23 after removing 2 unused)
- `src/folder_tool/folder_tool_ui_processing.py` (22 bare)
- `src/folder_tool/file_validation.py` (19 bare)
- `src/folder_tool/folder_tool_archive.py` (15 bare)
- `src/data_processing/.../folder_tool_tab.py` (13 bare)
- `src/function_generator/.../main_window.py` (12 bare)
- `src/rotation_converter/spatial_algebra.py` (7 bare → 5 after removing 2 unused)
- `src/rotation_converter/twist_screw.py` (3 bare)
- Various others (1-8 bare each)

Error code assignment by context:
- `self.attribute_name` on mixin class → `[attr-defined]`
- Return `numpy_array` → `[no-any-return]`
- GPU array index/slice → `[assignment]` or `[index]`
- Method call on optional → `[union-attr]`

### Phase 3: Verify Target Met
After Phases 1+2, count remaining bare `# type: ignore$`. Target: < 200.
If > 200, continue Phase 2 with additional files.

## Edge Cases
- Lines that have both a comment AND `# type: ignore` — preserve the comment, remove only the ignore
- Lines with `# type: ignore  # some comment` — remove only the ` # type: ignore` portion
- Multiline expressions — ignore on last token only, preserve structure

## Test Checkpoints
- After Phase 1: `python3 -m mypy --config-file mypy.ini . --no-error-summary 2>&1 | grep "unused-ignore" | wc -l` → should be 0
- After Phase 2: `grep -rn "# type: ignore$" src/ --include="*.py" | wc -l` → should be < 200
- Final: `python3 -m ruff check .` → zero violations
- Final: `python3 -m pytest -m unit -n auto --timeout=60` → passes

## Risk Register
| Risk | Mitigation |
|------|-----------|
| Removing an ignore that was masking a real error | Phase 1 only removes mypy-confirmed unused ignores; Phase 2 adds codes (not removes) |
| Ruff formatting drift | Run `ruff format` after changes |
| Line length exceeded by adding error code | Use `[attr-defined]` (13 chars) — minimal; ruff will flag if over 88 chars |

## Rollback Boundary
All changes are comment-only (no logic changes). Git revert is safe at any point.
