# Execution Plan: GH1705

## Story Summary

Assessment: Pragmatic Programmer — Decoupling (calculate_pressure_drop has 4 definitions)

## Analysis

### The 4 Definitions

| # | Location | Signature | Physics Domain |
|---|----------|-----------|----------------|
| 1 | `scrubber_calculator.py:375` | `(gas_velocity, gas_density, liquid_mass_flux, liquid_density, packing, packed_height, ...)` | Packed bed Eckert correlation (scrubber) |
| 2 | `pressure_drop_interface.py:451` | `(pipe_size, pipe_schedule, pipe_diameter, pipe_length, ...)` | Pipe friction — flexible public API |
| 3 | `pressure_drop_calculator/__init__.py:224` | `PressureDropCalculator.calculate_pressure_drop(self, pipe_diameter_m, pipe_length_m, roughness_m, ...)` | Pipe friction — legacy API class method |
| 4 | `calc_backend/routers/pressure_drop.py:18` | `calculate_pressure_drop(request: PressureDropRequest)` | Pipe friction — FastAPI handler, inline copy of #3 |

### What is Actually Duplicated

Definitions 3 and 4 are genuine duplicates. `calc_backend/routers/pressure_drop.py` contains an inline reimplementation of the exact same Darcy-Weisbach algorithm as `PressureDropCalculator.calculate_pressure_drop`. The router's own docstring states: "Uses an inline implementation matching the legacy PressureDropCalculator to avoid import issues."

Definitions 1, 2, and 3 are NOT duplicates:
- #1 (scrubber) uses different physics and serves a different engineering domain
- #2 (interface) is a higher-level public API wrapper with full unit conversion
- #3 (legacy class) is the canonical simple Darcy-Weisbach implementation

### Fix

Make `calc_backend/routers/pressure_drop.py` delegate to `PressureDropCalculator` from `upstream_drift_tools.process_calculators.pressure_drop_calculator`, eliminating the inline duplicate. The router response mapping stays unchanged.

## Implementation Steps

### Step 1: Update `pressure_drop.py` router

Replace the inline physics implementation with a call to `PressureDropCalculator`:

```python
from upstream_drift_tools.process_calculators.pressure_drop_calculator import (
    PressureDropCalculator,
    PressureDropResult,
)

_calculator = PressureDropCalculator()

@router.post("", response_model=PressureDropResponse)
def calculate_pressure_drop(request: PressureDropRequest) -> PressureDropResponse:
    """Calculate pressure drop using Darcy-Weisbach equation.

    Delegates to PressureDropCalculator from upstream_drift_tools.
    """
    try:
        result: PressureDropResult = _calculator.calculate_pressure_drop(
            pipe_diameter_m=request.pipe_diameter_m,
            pipe_length_m=request.pipe_length_m,
            roughness_m=request.roughness_m,
            flow_rate_kg_s=request.flow_rate_kg_s,
            temperature_k=request.temperature_k,
            pressure_pa=request.pressure_pa,
            molecular_weight_kg_mol=request.molecular_weight_kg_mol,
        )
    except (ValueError, ZeroDivisionError, OverflowError, TypeError) as exc:
        raise HTTPException(status_code=422, detail=str(exc)) from exc

    return PressureDropResponse(
        pressure_drop_pa=result.pressure_drop_pa,
        reynolds_number=result.reynolds_number,
        friction_factor=result.friction_factor,
        velocity_m_s=result.velocity,
        flow_regime=result.flow_regime,
        density_kg_m3=result.density,
        viscosity_pa_s=result.viscosity,
    )
```
