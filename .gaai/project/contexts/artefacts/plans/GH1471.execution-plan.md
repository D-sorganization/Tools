## Implementation Sequence

### Step 1: Fix LoD in mesh_generator.py
**File:** `src/glass_bath_fea/core/mesh_generator.py`
**Change:** Extract `mesh.points` and `mesh.cells_dict` into local variables before use.

Before (lines 96-101):
```python
nodes = mesh.points.T  # 3xN array
elements = mesh.cells_dict.get("tetra", np.array([])).T + 1  # 1-indexed
material_ids = self._assign_material_ids(mesh.points, elements.T - 1)
```

After:
```python
points = mesh.points
cells = mesh.cells_dict
nodes = points.T  # 3xN array
elements = cells.get("tetra", np.array([])).T + 1  # 1-indexed
material_ids = self._assign_material_ids(points, elements.T - 1)
```
