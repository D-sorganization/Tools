# Execution Plan: GH1697 — Full-Repo Ruff/Mypy/Format CI Coverage

## Summary

Add a weekly/nightly non-blocking GitHub Actions workflow that performs full-repo
ruff lint, ruff format check, and mypy type checks — capturing violation counts as
metrics to prevent ratchet accumulation. Also add T201 (print detection) to
`ruff.toml` so print() calls in `src/` are visible in delta checks.

## Approach

Follow the established pattern of `Code-Metrics.yml`: a scheduled + workflow_dispatch
job that is **informational only** (never fails CI). Reports violation counts as
GitHub Step Summary metrics. This is the exact pattern recommended in the story.

No new Python scripts required — the workflow uses ruff and mypy CLI directly with
shell arithmetic to count violations and write summaries.

## Implementation Sequence

### Step 1 — Add T201 (print detection) to ruff.toml

**File:** `ruff.toml`

Add `T201` to the `[lint]` `select` list. T201 detects `print()` calls.

The existing per-file-ignores already suppress T201 for `scripts/**/*.py` and
`scripts/*.py` — those are intentional CLI-use files and should remain excluded.

**Change:** In `[lint]` section, update `select`:
```toml
select = ["E", "F", "W", "I", "B", "UP", "T201"]
```

**Why not blocking right now:** The full-repo run will reveal how many existing
violations exist. We add T201 to delta-check now; the nightly job will count total
violations across the repo.

### Step 2 — Create nightly full-repo quality workflow

**File:** `.github/workflows/nightly-full-repo-quality.yml`

Trigger: `schedule: cron "0 3 * * 0"` (weekly Sunday at 3 AM UTC) + `workflow_dispatch`.

Job: `full-repo-quality` — runs on ubuntu-latest, never fails (continue-on-error: true
on each check step, final step always passes).

Steps:
1. Checkout (full depth)
2. Setup Python 3.12
3. Install ruff + mypy
4. **Ruff lint (full repo)** — run `ruff check . --output-format=json` to get JSON output,
   count violations, write to GITHUB_STEP_SUMMARY. Capture exit code but do not fail job.
5. **Ruff format (full repo)** — run `ruff format --check . 2>&1` to count files with
   format violations. Capture list, write count to GITHUB_STEP_SUMMARY.
6. **Mypy (full repo on src/)** — run `mypy src/ --ignore-missing-imports --no-error-summary`
   and count error lines. Exclude known-broken directories (same list as ci-standard.yml).
7. **Print() audit** — count files in `src/` containing print() calls (excluding
   comments/strings). Write count to summary.
8. **Summary table** — emit a markdown summary table with violation counts per check.
   Note which directories are still excluded from ruff.toml.

All steps use `continue-on-error: true` at the step level so the job always passes.
This matches the "non-blocking initially" requirement from the story recommendation.

### Step 3 — Verify ruff check on modified files

Run locally before committing:
- `ruff check ruff.toml` — N/A (TOML, not Python)
- `ruff check .github/workflows/nightly-full-repo-quality.yml` — N/A (YAML)
- Verify no unintended violations introduced by T201 addition in current staged files

## Edge Cases

| Case | Handling |
|------|----------|
| No Python files found | Each step gracefully handles empty output with fallback echo |
| ruff/mypy not installed | Install step covers this |
| Mypy finds 1000s of errors | continue-on-error: true; count is informational |
| T201 causes delta check failures in existing changed files | Acceptable — T201 is enforcement for new changes; existing violations tracked by nightly job |
| Excluded directories (src/data_processing etc.) | Document in GITHUB_STEP_SUMMARY as "excluded from ruff.toml" |
