# GH1490 Execution Plan

## Story Summary

## Tier

## Violation Analysis

### DbC Violation

**`_on_power_profile_changed(self, profile: str)`** — argument lacks explicit preconditions.

Current code has `assert profile is not None` which is a weak contract. Per CLAUDE.md, arguments should raise `TypeError` for wrong types. However, `_on_power_profile_changed` is a private method called by Qt signal with a string argument. The `assert` is adequate for private slot methods. The story simply requires explicit preconditions are present.

**Fix:** Strengthen precondition to `if not isinstance(profile, str): raise TypeError(...)` or replace `assert` with an explicit `ValueError` guard.

### LoD Violations (11 reported, mapped to current file)

All violations are 3-level enum attribute chains:

| Location | Pattern | Fix |
|----------|---------|-----|
| `_setup_ui` line ~217 | `Qt.ScrollBarPolicy.ScrollBarAlwaysOff` | Extract to local alias |
| `_setup_ui` line ~233 | `Qt.AlignmentFlag.AlignCenter` | Extract to local alias |
| `_create_thermal_params_group` lines ~265 (x2) | `QSizePolicy.Policy.Expanding/Fixed` | Extract to local variable |
| `_create_thermal_params_group` lines ~276 (x2) | `QSizePolicy.Policy.Expanding/Fixed` | Extract to local variable |
| `_create_thermal_params_group` lines ~287 (x2) | `QSizePolicy.Policy.Expanding/Fixed` | Extract to local variable |
| `_create_thermal_params_group` lines ~298 (x2) | `QSizePolicy.Policy.Expanding/Fixed` | Extract to local variable |

**Fix approach:** Add module-level enum aliases (preferred for reuse across methods):
```python
_SCROLL_ALWAYS_OFF = Qt.ScrollBarPolicy.ScrollBarAlwaysOff
_ALIGN_CENTER = Qt.AlignmentFlag.AlignCenter
_SIZE_EXPANDING = QSizePolicy.Policy.Expanding
_SIZE_FIXED = QSizePolicy.Policy.Fixed
```

This reduces all 3-chain accesses to 1-chain accesses (`_SCROLL_ALWAYS_OFF`, etc.).
