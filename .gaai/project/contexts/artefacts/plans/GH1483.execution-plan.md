# GH1483 Execution Plan

## Story Summary

Address DbC (precondition-as-assert) and LoD (deep attribute access) violations in
`src/rotation_converter/advanced_kinematics.py`, `src/rotation_converter/converter.py`,
and `src/rotation_converter/core.py`.

## Tier

Tier 2 — Core Team (3 source files to modify, existing test files to extend, 5 acceptance criteria)

## Violation Analysis

### DbC Violations — Replace bare `assert` with explicit `raise`

Python `assert` statements are disabled in optimized mode (`python -O`), making them
unreliable as DbC preconditions. Per project convention (same pattern used in GH1484,
GH1488, etc.), the fix is: replace `assert x is not None` with
`if x is None: raise TypeError(...)`.

The `require()` calls already present are correct and should stay.

### LoD Violation — `converter.py` line 58

In `Rotation.compose`:
```python
q = quaternion_multiply(self._q, other._q)  # accesses private _q on other
```
Fix: use public accessor `other.as_quaternion()` instead of `other._q`.

## Implementation Sequence

1. Fix `src/rotation_converter/core.py` — replace all bare asserts with `raise`
2. Fix `src/rotation_converter/advanced_kinematics.py` — replace bare asserts
3. Fix `src/rotation_converter/converter.py` — replace bare asserts + fix LoD violation
4. Extend tests in `tests/rotation_converter/test_rotation_converter_advanced.py`
   - Test that `None` inputs raise `TypeError` (not `AssertionError`)
   - Test that `compose` works via the public accessor path
5. Run `ruff check` and `ruff format` on modified files
6. Run pytest on rotation_converter tests

## Edge Cases

- `Rotation.compose`: Accessing `other._q` vs `other.as_quaternion()` — the public method returns a copy, so no mutation risk
- Internal helpers (`_validate_quaternion_array`, `_validate_unit_quaternion`) are private; only public-API asserts need fixing per DbC policy, but fixing internal ones improves consistency and correctness in `-O` mode
- `slerp` already has `require(0.0 <= t <= 1.0, ...)` — no shape/finiteness check on q1/q2; add a shape check after the None guard
