# GH1655 Execution Plan: Replace print() calls with logging

## Assessment

Current state: ruff T201 not enabled; 25 `print()` occurrences in src/ .py files.
- 2 in `src/rotation_converter/modern_robotics.py` (docstring examples, no noqa)
- 9 in `src/pendulum_simulator/tests/test_analytical_jacobians.py` (benchmark output)
- 7 in `src/pendulum_simulator/test_sim.py` (CLI script, no noqa)
- 6 with existing `# noqa: T201` in perf_test.py and signal_test.py
- 1 with existing `# noqa: T201` in `__main__.py` (version CLI output)
- 66 T201 violations in Jupyter notebooks (legitimate, need per-file-ignore)

## Approach

1. Add `import logging` + `_logger = logging.getLogger(__name__)` to `modern_robotics.py`

3. Add `import logging` + `_logger` to `test_analytical_jacobians.py`; replace 9 print calls with `_logger.debug()`
4. Add `# noqa: T201` to 7 print calls in `test_sim.py` (CLI script)
5. Update `pyproject.toml`: add `T201` to `[tool.ruff.lint] select`; add `T201` to `**/*.ipynb` per-file-ignores
6. Write 6 TDD tests in `tests/test_gh1655_print_to_logging.py`
