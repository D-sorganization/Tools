# GH1482 Execution Plan

## Story Summary

Address DbC and LoD violations in `src/python`:
- `src/python/shared/performance_utils.py`
- `src/python/src/core/plugin_manager.py`
- `src/python/src/help/help_system.py`

## Tier

Tier 2 — Core Team (3 source files, 5 acceptance criteria)

## Violation Analysis

### performance_utils.py

**DbC Violations:**
- `OptimizedFileScanner.__init__`: `assert max_workers is not None` — weak; must raise `TypeError` for non-int and `ValueError` for out-of-range.
- `scan_directory_parallel`: `assert root_path is not None` — weak; must raise `TypeError` for non-Path, `ValueError` for empty string.
- `scan_subdirectory` (nested): `assert directory is not None` — weak; must raise `TypeError`.

**LoD Violations:**
- Line 60: `os.path.getmtime(root_path)` — 3-level chain `os.path.getmtime`. Fix: use `Path.stat().st_mtime` directly on `root_path` (a Path object) or extract via `_get_mtime(path)` helper.
- Line 120: `os.path.getmtime(root_path)` — same fix.

Fix strategy: Replace `os.path.getmtime(root_path)` with `root_path.stat().st_mtime` — since `root_path` is already a `Path` object, this is only 2-level (`obj.method()`). Remove unused `os.path` dependency if no longer needed.

### plugin_manager.py

**DbC Violations:**
- `PluginManager.__init__`: `assert repo_root is not None` — weak; must raise `TypeError` for non-Path.
- `get_tool_by_name`: `assert name is not None` — weak; must raise `TypeError` for non-str.

**LoD Violations:**
- Line 165: `manifest_path.parent.name` — 3-level chain. Fix: extract `parent_dir = manifest_path.parent` then use `parent_dir.name`.
- Line 169: `manifest_path.parent.glob("*.py")` — 3-level chain. Fix: use extracted `parent_dir.glob("*.py")`.

### help_system.py

**DbC Violations** (using `assert` instead of raise):
All private markdown handler functions (`_handle_code_block`, `_handle_horizontal_rule`, `_handle_table_line`, `_handle_header`, `_handle_list_item`, `_handle_paragraph`) use `assert line is not None` — weak.
`create_help_menu_actions`: `assert parent is not None` — weak.
`HelpDialog.__init__`: `assert title is not None` — weak.

Fix: Replace all `assert x is not None` with `if x is None: raise ValueError(f"x must not be None")` or type checks where appropriate. For private helpers (`_handle_*`), since they are internal functions called only from `_markdown_to_html`, lightweight type guards suffice. For public API (`create_help_menu_actions`, `HelpDialog.__init__`), use explicit `TypeError`/`ValueError`.

Note: The `_handle_*` functions are private (single underscore prefix). DbC on private helpers should still raise rather than assert.

## Edge Cases

- `max_workers = 0`: should be allowed (falls through to sequential mode) or raise? Current code uses `max_workers > 1` check. Value 0 is effectively sequential. Allow as valid (>= -1).
- `max_workers = -1`: the sentinel for "auto". Allow.
- PyQt6 imports in tests: use `unittest.mock` or `pytest.importorskip("PyQt6")`.

## Test Checkpoints

2. `scan_directory_parallel` works on a real temp directory
