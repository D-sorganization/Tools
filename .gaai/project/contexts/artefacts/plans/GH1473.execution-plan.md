# GH1473 Execution Plan

## Story Summary
Address DbC and LoD violations in `src/inertia_calculator/python/inertia_calculator/ui/pyqt6/main_window.py`.

## Approach
Follow established project DbC conventions: `TypeError` for wrong types, `ValueError` for out-of-range.
Replace `assert` with proper `raise` statements.
Fix LoD violations by assigning deep attribute accesses to local variables.

## Implementation Steps

### Step 1: Fix DbC in `_display_results`
- Remove `assert ixx is not None` (incorrect DbC pattern)
- Add `isinstance` type check raising `TypeError` for non-float arguments
- Add `math.isfinite` check raising `ValueError` for non-finite floats
- Document preconditions in docstring

### Step 2: Fix DbC in `_validate_inertia`
- Remove `assert ixx is not None`
- Add `isinstance` + `math.isfinite` checks raising `TypeError`/`ValueError`
- Document preconditions in docstring

### Step 3: Fix LoD at lines 210, 226 in `_setup_ui`
- Line 210: `Qt.ScrollBarPolicy.ScrollBarAlwaysOff` → local var `ScrollBarOff = Qt.ScrollBarPolicy.ScrollBarAlwaysOff`
- Line 226: `Qt.AlignmentFlag.AlignCenter` → local var `AlignCenter = Qt.AlignmentFlag.AlignCenter`

### Step 4: Fix LoD at lines 269-270 in `_create_primitive_tab`
- Lines 270/270: `QSizePolicy.Policy.Expanding`, `QSizePolicy.Policy.Fixed` → local vars

### Step 5: Fix LoD at lines 303, 380 in tab creation methods
- Review exact LoD issues at those lines and apply local-var pattern

### Step 6: Fix LoD at lines 587, 588 in `_validate_inertia`
- `np.linalg.cholesky` → `linalg_cholesky = np.linalg.cholesky`
- `np.linalg.LinAlgError` → `LinAlgError = np.linalg.LinAlgError`

### Step 7: Add tests
- Tests for DbC preconditions on `_display_results` and `_validate_inertia` (need headless mock approach)
