# GH1702 Execution Plan: Remove Global E501 Suppression

## Approach

Tier 2 delivery. Config change in `ruff.toml` with targeted `# noqa: E501` on
lines that cannot be shortened without harming readability.

## Steps

1. Audit current E501 violations in `src/` by running `ruff check --select E501 src/`
2. Remove `"**/*.py" = ["E501"]` from `[lint.per-file-ignores]` in `ruff.toml`

5. Commit and create PR
