# GH1464 Execution Plan: DbC and LoD in src/financial_calculator

## Story Summary

Address TDD, DRY, DbC, and LoD violations in
`src/financial_calculator/python/financial_calculator/ui/pyqt6/main_window.py`.

## Tier Assessment

Tier 1 (MicroDelivery): single file, 5 ACs, complexity ≤ 2, no specialist triggers.

## Violations to Fix

### LoD Violations (deep attribute access)

| Location | Violation | Fix |
|----------|-----------|-----|
| `_create_input_panel` | `Qt.ScrollBarPolicy.ScrollBarAlwaysOff` (3-level) | Extract to module-level `_SCROLLBAR_OFF` constant |
| `_create_input_panel` | `QFont.Weight.Bold` (2-level) in `setFont()` | Extract to module-level `_BOLD_WEIGHT` constant |
| `_create_results_panel` | `QFont.Weight.Bold` (2-level) in `setFont()` | Use `_BOLD_WEIGHT` constant |
| `_create_summary_tab` | `QFont.Weight.Bold` (2-level) in `setFont()` | Use `_BOLD_WEIGHT` constant |

### DbC Violations (missing preconditions)

| Function | Violation | Fix |
|----------|-----------|-----|
| `FinancialCalculatorEngine.calculate()` | Only `assert plant_capacity is not None` — no type/range checks | Replace with `isinstance`/range guards raising `TypeError`/`ValueError` |
| `FinancialCalculatorEngine.generate_projections()` | Only `assert years is not None` | Replace with `isinstance` + range guard |
| `FinancialCalculatorMainWindow.__init__()` | No precondition on `parent` | Add `isinstance(parent, QWidget)` or `None` check |
| `_update_results()` | Only `assert results is not None` | Replace with `isinstance(results, FinancialDesign)` check |
| `_update_projections()` | Only `assert projections is not None` | Replace with `isinstance(projections, list)` check |

## Test Checkpoints

- New `TestFinancialCalculatorEngineDbC` class covering all TypeError/ValueError paths
- New `TestFinancialCalculatorMainWindowDbC` class covering `__init__`, `_update_results`, `_update_projections`
- All 21 tests pass with `PYTHONPATH=src/financial_calculator/python`

## Risk Register

Low: The changes are additive (stronger preconditions) and do not change behavior for valid inputs.
