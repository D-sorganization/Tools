# GH1481 Execution Plan

## Story
Adversarial Assessment: Address TDD, DRY, DbC, and LOD in src/project_packer

## Tier Assessment
Tier 2 — Core Team (complexity 3: 3 files, 5 specific violations, clear fix path)

## Pre-flight Analysis

### DbC Status (Pre-existing — Already Fixed)
All DbC violations identified in the story were already present in the codebase with `assert` guards:
- `__init__`: `assert root is not None`
- `_setup_header`, `_setup_source_section`, `_setup_output_section`, `_setup_actions`, `_setup_status_section`: `assert parent is not None`
- `copy_folder_contents`: `assert source is not None`
- `should_include_file`: `assert file_path is not None`
- `should_include_directory`: `assert dir_path is not None`
- `_should_include_item`: `assert item is not None`
- `update_status`: `assert message is not None`

No DbC work required.

### LoD Violations to Fix

| File | Line | Violation | Fix |
|------|------|-----------|-----|
| `build.py` | 31 | `Path(__file__).parent.absolute()` | Extract `.parent` to `script_parent`, then call `.absolute()` |
| `build.py` | 53 | `sys.stderr.write()` | Extract `sys.stderr` to `stderr = sys.stderr` |
| `build_exe.py` | 31 | `importlib.util.find_spec(...)` | Import `find_spec` directly from `importlib.util` |
| `folder_packer_gui.py` | 387, 391 | `file_path.suffix.lower()` | Extract `suffix = file_path.suffix`, then `lower_suffix = suffix.lower()` |
| `folder_packer_gui.py` | 404 | `dir_path.name.lower()` | Extract `dir_basename = dir_path.name`, then `dir_name = dir_basename.lower()` |

## Implementation Sequence

1. Fix `build_exe.py`: change `import importlib.util` + `importlib.util.find_spec(...)` to `from importlib.util import find_spec` + `find_spec(...)`
2. Fix `build.py`: extract `sys.stderr` and `Path(__file__).parent` to intermediate vars
3. Fix `folder_packer_gui.py`: extract suffix and dir name before calling `.lower()`
4. Create `tests/project_packer_fixes/` with tests for all fixed functions (note: `project_packer` is in norecursedirs, so use `project_packer_fixes` directory name)
5. Verify ruff check, ruff format, full test suite

- Low: `project_packer` in `norecursedirs` — test directory named `project_packer_fixes` to avoid exclusion
