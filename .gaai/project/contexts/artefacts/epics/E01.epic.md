# E01: Interactive force-source optimization comparison

## Purpose

Enable a user to choose a starting swing pose, optimize a selected mechanical
objective, and compare the resulting motions and loads in one understandable view.

## Scope

- Select starting arm and wrist positions and an optimization objective.
- Configure wrist torque limits through 30 N m and search thoroughness.
- Run optimization from the visible starting pose.
- Compare synchronized animations with clubhead-speed and joint-torque plots.
- Load versioned registered-study exports for reproducible comparison.

## Out of Scope

- Real-time motion capture fitting.
- Claims that the two-link result prescribes an individual golfer's technique.
- Three-dimensional golfer or flexible-shaft visualization.

## Stories

- E01S01: Configure, optimize, and compare force-source swing strategies.

## Success Metrics

- A user can complete the select-pose-to-comparison journey without editing code.
- All six objectives can be inspected with synchronized motion and supplemental plots.
- The interface makes limits, convergence, and model caveats visible.

## Dependencies

- Versioned study exports from UpstreamDrift.
