## Epic: Port Electrode Advisor to Rust Kernel for UI Responsiveness

### Background

The Electrode Advisor in the `Tools` repository is currently driven by a pure Python backend (`electrode_advancement_calculator.py` and `electrode_advisor.py`). Due to the frequency of state updates needed for the 3D GUI (`GlassBath3DViewer.tsx` and `ElectrodeAdvisorCalculator.tsx`) and the real-time calculation of complex electrode placements, drafting envelopes, and advancement rates, the Python implementation can exhibit sluggishness and frame-drops during active user interaction.

### Objective

Migrate the computational and geometric projection layers of the Electrode Advisor to the shared Rust kernel (`rust_core`). This will provide native execution speeds, memory safety, and immediate UI responsiveness (0ms blocking on the event loop) by moving layout, consumption rates, and placement mathematics out of the Python interpreter.

### Scope & Architectural Integration

1. **Target Rust Crate**: `Tools/rust_core/tools-core` or a new sibling crate `Tools/rust_core/electrode-advisor`.
2. **Integration Method**: Expose the Rust logic via `PyO3` / `maturin` bindings, adhering to the established pattern (similar to `thermo_solver`).
3. **Data Parity**: Maintain strict ABI compatibility with the existing JSON manifest contract generated by `to_manifest()` in `vessel_drafter/models/electrode_advisor.py`.

## Detailed Implementation Plan (Phases)

### Phase 1: Rust Core Primitive Implementation

**Goal**: Re-implement core data structures and mathematical primitives in Rust.

1. **Create Rust Data Structures**:
   - Port `BathDefaults`, `ElectrodeDefaults`, `DraftingEnvelope`, and `ElectrodePlacement` to Rust structs.
   - Implement `#[pyclass]` macros on these structs to allow direct Python interaction.
2. **Implement Core Math**:
   - Translate the `_build_default_placements` logic from Python to Rust.
   - Utilize native trigonometric functions (`f64::cos`, `f64::sin`) for exact placement calculations.
   - Implement the `ElectrodeAdvancementCalculator` logic (currently in `electrode_advancement_calculator.py`) in Rust for high-speed consumption sweeps.
3. **Unit Testing**:
   - Write native Cargo tests ensuring zero drift between Python output and Rust output for edge-case electrode geometries (e.g., 1, 3, and 6 electrode configurations).

### Phase 2: PyO3/Maturin Bindings

**Goal**: Wire the Rust mathematical core directly into the Python backend.

1. **Create `lib.rs` Expositions**:
   - Bind the calculation engines and struct generators to Python modules via `#[pymodule]`.
2. **Expose Layout Generator**:
   - Create a Rust equivalent of `build_default_electrode_advisor_layout()` that returns the full `ElectrodeAdvisorLayout` object directly to Python memory without serialization overhead.
3. **Compile & Link**:
   - Update `Cargo.toml` to ensure the module builds properly with `maturin develop --release`.

### Phase 3: Python Facade and Deprecation

**Goal**: seamlessly substitute the backend without breaking the frontend Web UI.

1. **Adapter Layer (`rust_kernel.py`)**:
   - Implement the identical backend resolution logic used elsewhere (`GAS_THERMO_BACKEND=rust|auto|python`).
   - If `auto` or `rust` is selected, import the `maturin` compiled wheel.
2. **Manifest Generation Optimization**:
   - Move the `to_manifest()` dictionary generation to Rust using `serde_json` or native Python dictionary macros inside PyO3, skipping the Python instantiation entirely when streaming state to the UI.
3. **Legacy Deprecation**:
   - Add `warnings.warn("...", DeprecationWarning)` to the pure Python functions using the established `mark_legacy` standard.

### Phase 4: Verification and CI/CD Quality Gates

**Goal**: Ensure strict compliance and performance profiling.

1. **Parity Tests**:
   - Implement a new test suite (e.g., `test_electrode_advisor_parity.py`) that strictly asserts `assert_almost_equal` between the legacy Python outputs and the new Rust bindings.
2. **Performance Benchmarking**:
   - Use `pytest-benchmark` to quantify the calculation time difference. The goal is >10x speedup for placement sweeps.
3. **Linting and Health Checks**:
   - Verify `cargo clippy`, `cargo fmt`, and the Python CI (`ruff`, `mypy`, `black`) all pass.

## Developer Instructions (Getting Started)

1. Navigate to the Rust workspace: `cd Tools/rust_core/`
2. Generate the new module or add to `tools-core`: `cargo new electrode-advisor --lib`
3. Edit `Cargo.toml` to include `pyo3 = { version = "0.20", features = ["extension-module"] }`.
4. Begin by migrating the structures from `Tools/src/vessel_drafter/python/vessel_drafter/models/electrode_advisor.py`.
5. Constantly test locally with `maturin develop` and verify using the existing Python unit tests in `Tools/tests/shared/python/process_calculators/`.
