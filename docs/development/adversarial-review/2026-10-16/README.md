## Executive Read

Tools is the fleet's "DRY layer": a 692k-LOC Python monorepo (plus 970 TS/TSX, 114 Rust, 142 MATLAB files) that is simultaneously a shared engineering library (`src/shared/python/sidekick`, 78k LOC), a 93k-LOC golf-impact desktop/web app (`rate_of_closure`), an industrial SCADA backend (`p1am_control_system`), and a self-describing governance apparatus (117 scripts, 26.8k LOC; 43 architecture meta-tests; a 9.7 MB "module inventory" manifest). What is strong: the rotation kernel is correct for all 12 Euler conventions (verified against SciPy to 1e-15), the P1AM auth layer is genuinely fail-closed with constant-time key compare, `safe_eval` is a competent AST allowlist, and the ball-flight integrator is sane. The three things that would hurt most:

1. **Process-calculator numerics are wrong where money is spent.** WGS reactor volume is low by 22.4× (kmol/h divided by GHSV as if it were Nm³/h) and heat duty wrong by ×(1000·y_CO); the Lucas viscosity path is low by 10–40×, so any wet syngas gets a 4× too-low mixture viscosity and a wrong ΔP; the "acid-gas dewpoint" reports HCl condensing at −152 °C because it models pure-component condensation, not aqueous acid dew point; the baghouse silently substitutes N₂ properties for any species key it does not recognise (lowercase `"h2"` halves the air-to-cloth ratio). Every one of these passes the test suite because the tests assert `> 0`.
2. **The public-API contract is signature theatre.** The AST baseline compares argument names and annotation _strings_; 51 of 251 sidekick modules (20%) are fully unguarded because they declare `__all__ = []` or none at all — 15 `lab/mocap` modules export 94 public classes/functions behind an empty `__all__`. Nothing checks behaviour, exceptions, units or return values.
3. **Governance cost dwarfs the governed content, and several gates describe a world that does not exist.** Nine design-manual check scripts (3.4k LOC) plus a 3,892-entry content-hash manifest, a custom git merge driver and a pre-merge-commit hook govern _one_ registered calculation. CI's ruff/mypy/bandit run on changed files only; the "full repo" steps are `continue-on-error`. `requirements.txt` declares `mypy==2.4.0` as "THE one pin" while CI greps that line out and installs 1.13.0. AGENTS.md documents ten overnight Jules workflows; three exist.

## Patterns and Approaches Worth Adopting

- **Unit-typed quantities at the kernel boundary.** F-TL-001, 006, 011, 012, 014 are unit confusions in bare floats. `pint`, or a 40-line `NewType` family (`KmolPerHour`, `Nm3PerHour`), makes `feed_rate / ghsv` a type error. At minimum suffix every public numeric argument with its unit — `flight/` and `rate_of_closure/` already do this and have no unit bugs.
- **Reference-value tests, not `> 0` tests.** One test per formula whose name is the hand-computed answer with units. Property tests (Hypothesis is already a dependency) for monotonicity, limits and symmetry — `K(T)` decreasing for exothermic, `f(Re)` decreasing, μ*mix between the pure components — catch the \_class* of bug without reference data.
- **Mutation testing as the honesty check.** `mutmut` on `process_calculators` would show most arithmetic mutants survive. One afternoon of this is worth more than 12.9k LOC of meta-tests.
- **Fail loudly on unknown inputs.** `dict.get(species, DEFAULT)`, `continue` on unknown species, `np.nan_to_num` on filter output, `Z = clamp(0.1, 1.5)` — four modules "recover" from conditions that mean the answer is wrong. In engineering code the only safe default is an exception.
- **Model selection is part of correctness.** The acid-gas calculator applies a correct formula to the wrong physics. Each calculator should carry a "Model and validity" docstring section, and tests should probe the stated boundary.
- **Behavioural API contracts over signature baselines.** Golden `(inputs → outputs)` files for the ~30 entry points downstream repos call, regenerated only with a written reason, protect consumers; annotation-string baselines protect nobody and train reflexive regeneration.
- **Governance should be cheaper than what it governs.** Before adding a check script, write down who reads its output and what decision changes. Prefer one `make check` over nine `python -m scripts.check_*` incantations in CLAUDE.md.
- **Single source of truth for versions and rules — then derive.** mypy/numpy/ruff versions, the size limit, the Python floor and the workflow list each live in 2–4 places that disagree. A `config/policy.toml` read by scripts and by a doc generator removes the drift class.
- **Separate the library from the apps.** A wheel consumed by two repos should not contain a React bundle; apply the `movement_optimizer` pattern to `rate_of_closure` and `p1am_control_system`.
- **SOS filters and `sosfiltfilt` by default**; record the effective two-pass response in metadata.
- **Dead-code sweeps (`vulture`) after every compat-shim PR**; `HAS_THERMO = False` and 43 dead ruff entries are what happens otherwise.
- **Agent-written docs need a reality test.** Any doc naming a file, workflow or command should have a trivial existence test — the pattern is already in `tests/ops`; it was never pointed at AGENTS.md.
