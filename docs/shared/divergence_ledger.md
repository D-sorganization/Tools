## Ruling vocabulary

- `tools-canonical`: Tools is the source; UD consumes (vendor pin / wheel). Tools-only PRs allowed.
- `ud-canonical`: UD is the source; Tools must not shadow it.
- `split`: Both halves are intentionally different estimands/artifacts; a change to either side is paired cross-repo work.
- `deferred`: Owner ruling pending on the seam epic; until ruled, a Tools change needs a paired UD PR (UD-PAIR: D-sorganization/UpstreamDrift#N).
