## 2024-07-27 - Prevent Memory Leak and Redundant Video Reloading during Edit
**Learning:** In React, performing unconditional side effects in the render body (like `URL.createObjectURL(file)` and reassigning `video.src`) triggers an object URL memory leak that persists until document unload. When combined with state-updating inputs (like a `<input type="range">`), this causes a massive memory leak and continuous DOM layout thrashing.
**Action:** Always wrap `URL.createObjectURL` side effects in a `useEffect` with proper cleanup (`URL.revokeObjectURL`) and a minimal dependency array to avoid memory leaks and unneeded browser repaints.
