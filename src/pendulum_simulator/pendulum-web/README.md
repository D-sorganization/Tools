# Tauri + React + Typescript

This template should help get you started developing with Tauri, React and Typescript in Vite.

## Force Source Lab

The double-pendulum page includes a synchronized comparison lab for five
registered objectives: Coriolis impulse, Coriolis energy transfer,
squared-speed impulse, squared-speed energy transfer, and clubhead speed.

The lab provides:

- five animations on one shared timeline;
- continuously interpolated animation frames with 0.10×–2.00× playback speed
  and a 0.5 ms scrubber;
- aligned clubhead-speed, shoulder-torque, and wrist-torque plots;
- a selectable initial arm angle and wrist cock, inherited from the visible
  simulator pose;
- quick and thorough browser searches with a user-selectable wrist-torque limit
  up to 30 N m;
- golf-like qualification that requires a non-looping first pass, rightward
  clubhead motion within 15 degrees of horizontal, and impact within 90% of the
  model's full downward reach;
- objective score, impact speed, wrist program, robustness, convergence, and
  boundary diagnostics; and
- import of versioned `force-source-comparison/v1` JSON artifacts.

Angles follow the physics engine exactly: arm angle is absolute from downward
vertical, wrist cock is relative to the arm, and the club's absolute angle is
their sum. The registered −126° / −90° pose places both hands and clubhead above
the shoulder in the comparison view. The SVG comparison uses the same vertical
screen transform as the main canvas; a regression test protects this convention.
The loaded comparison pose and the pose selected for the next browser
optimization are shown separately. Playback starts paused at time zero so the
loaded top-of-backswing geometry can be inspected before motion begins.

The checked-in `public/force-source-comparison.json` is generated by the
UpstreamDrift registered Python study. It gives the app a reproducible default
comparison while the browser optimizer supports interactive pose exploration.
Browser-generated results report “Nominal only”; the registered Python study is
the source for local perturbation robustness statistics.

Run the web app with:

```powershell
npm ci
npm run dev
```

The model is intentionally idealized. High speed-only results are not human
performance predictions, and force-source terms depend on the selected
generalized coordinates. Boundary hits signal that the best point is at the
edge of the tested search space.
