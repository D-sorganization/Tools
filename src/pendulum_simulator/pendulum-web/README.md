# Tauri + React + Typescript

This template should help get you started developing with Tauri, React and Typescript in Vite.

## Force Source Lab

The double-pendulum page includes a synchronized comparison lab for six
registered objectives: Coriolis impulse, Coriolis energy transfer,
squared-speed impulse, squared-speed energy transfer, clubhead speed, and signed
grip-force impulse along the hand path.

The lab provides:

- up to six animations on one shared timeline and a fixed-hub comparison frame;
- continuously interpolated animation frames with 0.05×–3.00× playback speed
  and a 0.25 ms scrubber;
- aligned clubhead-speed, shoulder-torque, and wrist-torque plots;
- direct numeric initial arm-angle and wrist-cock entry, plus controls to copy
  the loaded study or visible simulator pose;
- quick, thorough, and research browser searches with explicit candidate,
  integration, robustness, joint, impact, and torque controls;
- independently selectable wrist-torque limits and granularity up to 30 N m;
- golf-like qualification that requires a non-looping first pass, rightward
  clubhead motion within 15 degrees of horizontal, and impact within 90% of the
  model's full downward reach;
- objective score, impact speed, wrist program, robustness, convergence, and
  boundary diagnostics; and
- import of versioned `force-source-comparison/v1` JSON artifacts.

Angles follow the physics engine exactly: arm angle is absolute from downward
vertical, wrist cock is relative to the arm, and the club's absolute angle is
their sum. The registered −126° / −90° pose places both hands and clubhead above
the shoulder in the comparison view. The SVG comparison uses the same vertical
screen transform as the main canvas; a regression test protects this convention.
The loaded comparison pose initializes the editable optimization pose. Playback
starts paused at time zero so the top-of-backswing geometry can be inspected.
Unchecking fixed-hub mode translates the camera to align impact; it never moves
the physical hub in the model.

The checked-in `public/force-source-comparison.json` retains five scenarios from
the UpstreamDrift registered Python study and adds a provenance-labelled
research-depth hand-path scenario generated by the Tools browser engine. It gives
the app a reproducible six-way default while the same engine supports interactive
pose exploration. `npm run generate:force-source` deterministically regenerates
the sixth scenario. Browser-generated results include held-out pose/torque
perturbation trials; the Python study remains the source for the five historical
scenarios.

Run the web app with:

```powershell
npm ci
npm run dev
```

The model is intentionally idealized. High speed-only results are not human
performance predictions, and force-source terms depend on the selected
generalized coordinates. Boundary hits signal that the best point is at the
edge of the tested search space.
