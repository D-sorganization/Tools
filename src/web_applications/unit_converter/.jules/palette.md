## 2025-01-29 - Hidden Search Functionality

**Learning:** The unit search input is hidden via `display: none` and lacks a visible trigger (like a button or icon) to activate it. This makes the search feature completely inaccessible to users unless they know a secret trick (which doesn't seem to exist) or if it's unfinished.
**Action:** In future, ensure that features toggled via visibility have accessible and obvious triggers (e.g., a "Search" button next to the dropdown).
