## 🎓 For Your First Foray

### Don't Worry!

**TypeScript/JavaScript is similar to Python**, so you'll pick it up quickly:

**Python**:

```python
def greet(name):
    return f"Hello, {name}!"
```

**TypeScript** (similar!):

```typescript
function greet(name: string): string {
  return `Hello, ${name}!`;
}
```
