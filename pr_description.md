💡 What
Wrapped the data-entry inputs and calculate button in a native `<form>` element and updated the button to use `type="submit"`.

🎯 Why
Previously, the calculator required users to manually click the "Calculate" button or navigate to it and press Enter/Space. Wrapping it in a form enables native "Enter" key submission from any input field, improving data entry speed and efficiency.

📸 Before/After
Visuals remain identical, but functionality is enhanced to support Enter-key submission.

♿ Accessibility
Improves keyboard accessibility by supporting the standard "Enter" to submit pattern expected by users for data entry forms.
